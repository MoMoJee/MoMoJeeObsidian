# 3.3.4 专题总结：外反射半波损失与全反射相移的核心辨析

### 一、 核心概念梳理与总结

在前面关于边值关系和菲涅耳公式的讨论中，我们可以看到光在经过介质界面发生反射时，会出现不同形式的附加相位改变。很多时候这些相位改变被统称为相移，但在物理成因和特征上有着严格的区别。

1. **半波损失的理论基础**：
   正如笔记 [[3.3.1 反射光的相移突变与半波损失]] 中所述，半波损失现象的物理原因来源于麦克斯韦电磁场理论中的切向电场边值边界条件定律（即 $E_{1t} = E_{2t}$）。当光从光疏介质射向极化电磁阻碍较大的光密介质，或者遇到高电导率金属时，为了满足边界交界处的能流受迫匹配平衡，反射场必须相对于入射场发生反向，从而表现为外反射在法线附近的复振幅反射系数出现负号。
   在实验上，根据笔记 [[3.3.3 维纳实验(光波交互本源)]] 探讨的内容，正是这固定产生的半个波长的突变，令电场在镜面上绝对相互抵消耗损形成干涉波节，才由照相底片彻底分离且认定了感光的主效应成分。

2. **全反射相移的形成原因**：
   根据推导（见笔记 [[3.2.3 内反射与全反射临界角]]），光在发生内反射（光密到光疏）且入射角大于全反射临界角 $i_c$ 之后，电磁场边界条件迫使电场波在第一介质以外的光疏介质超浅层表面激发了一种局域态的波动现象，也就是所谓的作用域极短的隐失波场拖尾（详细解释见 [[3.4.1 隐失波(Evanescent Wave)的产生]]）。能量在经历这个波尾延展的过程再重新返回原介质，造成了一定时间上的相位滞后效应。

### 二、 两类相移特性的严格区别对立比对

为了能在解决干涉偏振相关的复杂光程计算时避免将半波引起的瞬变错认成其他附加相移，现在将两者做下列核心分离对照：

1. **发生的界面前提不同方向**：
   - **半波损失**产生时，必然伴随着外反射的特定角度段。此时光必须从光疏（$n_1<n_2$）射向光密表层。
   - **全反射产生带参特有相移**则恰好相反，必须发生在内反射的临界点之后。其光传播方向始终是由内向外照射（即由光密 $n_1$ 射到光疏介质 $n_2$ 或处于折射率更低环境）。

2. **附加改变的物理形态属性相反**（阶跃相移 相比于 渐变连续相移）：
   - **半波损失**是一种瞬间**固定为 $\pi$ 的阶梯式跳变定值相移**。这一突变等价于强行在光路补偿计算上添加刚好 $\pm \frac{\lambda}{2}$（半个波长）恒定差距。除了掠射阶段的两波偏振特性统一翻折，光疏往光密打在垂直射入附近的阶跃都是瞬间的、与角度变化呈突变的关系。
   - 全反射引起的相移并不是瞬间翻转180度，而是在光密介质越超向外发射的临界发生后，附加出的额外后拖的具有分数形式连续解的推延**特征迟缓角 $\delta$**（例如 $\delta < 180^\circ$ 不同实数角度）。它的延迟值完全随着超过临界值的逐渐加大而表现为逐渐起平滑递增的连续推演角度。

3. **偏振转化的最关键不同作用： $s$ 分量和 $p$ 分量的相差一致性差异**
   - 由于外反射的**半波损失**一旦符合条件，其 $\pi$ 的相跃会在 $s$ 和 $p$ 正交拆分的双偏振振动上往往以同步或者在基准坐标内互相翻折的表现而完成整体反射。因而两分量间即使加减了相同的 $\pm \pi$，不会对 $s$ 分量或 $p$ 分量引起除常数整数倍半周期外的不同相位差偏折。因此线偏振光受到半波损失射出的仍大体多半还是线偏光。
   - 而正如上文讨论所附带指出的，内全反射因为阻抗受波特性（如 $\delta_p \neq \delta_s$ 公式差异），会导致 p 分量在边界上被隐失波滞留的相移角要更加滞后于 s 振动面的波前延迟角度这必将使得相互间产生了一不可忽视连续带角度变量的实质不一相差错乱 （$\Delta\delta = \delta_p - \delta_s \neq 0$）。因此全反射之后原本同步的线偏振，其 $s$ 和 $p$ 相遇后被推迟成了互相非整数延宕不同步的螺旋振荡椭转。这是用于解释人工生产转化光波相位从最初的一维线态转为了**非单一相位差叠加的极佳介质温床（椭圆或圆偏振光发生器如菲涅尔棱体）核心成因。**
