# 习题 3.2.1 双层介质同轴电缆的电场分布与电容漏电阻

## 题目
同轴电缆内导体半径为 $a$，外导体半径为 $c$，内外导体之间填充两层有损耗介质：
- 内层（$a \leq \rho \leq b$）：介电常数 $\varepsilon_1$，电导率 $\sigma_1$
- 外层（$b \leq \rho \leq c$）：介电常数 $\varepsilon_2$，电导率 $\sigma_2$

两层介质的分界面为半径 $b$ 的同轴圆柱面。外加电压为 $U_0$，试求：
1. 介质中的电流密度和电场强度分布；
2. 同轴电缆单位长度的电容及漏电阻。

---

## 解答

### （1）电流密度与电场强度分布

**核心思路**：恒定电场满足 $\nabla\cdot\vec{J}=0$，在柱对称结构中，通过任意半径为 $\rho$、单位长度圆柱面的漏电流 $I$ 为常量（与 $\rho$ 无关），因此两层中的 $J_\rho$ 形式相同。

设单位长度漏电流为 $I$，在两层介质中：（背诵）

$$\vec{J} = \vec{e}_\rho\frac{I}{2\pi\rho} \quad (a \leq \rho \leq c)$$

> ==注意：$\vec{J}$ 的法向分量在分界面 $\rho = b$ 处连续，这正是恒定电场边界条件 $J_{n1}=J_{n2}$ 的体现。==

由 $\vec{J}=\sigma\vec{E}$ 分别代入两层的电导率：

**内层** $(a \leq \rho \leq b)$：

$$\vec{E}_1 = \frac{\vec{J}}{\sigma_1} = \vec{e}_\rho\frac{I}{2\pi\sigma_1\rho}$$

**外层** $(b \leq \rho \leq c)$：

$$\vec{E}_2 = \frac{\vec{J}}{\sigma_2} = \vec{e}_\rho\frac{I}{2\pi\sigma_2\rho}$$

由总电压确定 $I$：

$$U_0 = \int_a^b E_1\,d\rho + \int_b^c E_2\,d\rho = \frac{I}{2\pi}\left(\frac{\ln(b/a)}{\sigma_1} + \frac{\ln(c/b)}{\sigma_2}\right)$$

从而：

$$I = \frac{2\pi U_0}{\dfrac{\ln(b/a)}{\sigma_1} + \dfrac{\ln(c/b)}{\sigma_2}}$$

代回得到各量的最终表达式（以外加电压 $U_0$ 表示）：

$$\vec{J} = \vec{e}_\rho\frac{U_0}{\rho\left(\dfrac{\ln(b/a)}{\sigma_1}+\dfrac{\ln(c/b)}{\sigma_2}\right)}$$

$$\vec{E}_1 = \vec{e}_\rho\frac{U_0}{\sigma_1\rho\left(\dfrac{\ln(b/a)}{\sigma_1}+\dfrac{\ln(c/b)}{\sigma_2}\right)}, \quad a \leq \rho \leq b$$

$$\vec{E}_2 = \vec{e}_\rho\frac{U_0}{\sigma_2\rho\left(\dfrac{\ln(b/a)}{\sigma_1}+\dfrac{\ln(c/b)}{\sigma_2}\right)}, \quad b \leq \rho \leq c$$

---

### （2）单位长度电容和漏电阻

**漏电阻**：两层介质相当于两段串联电阻，每层单位长度漏电阻为：

$$R_{l1} = \frac{1}{2\pi\sigma_1}\ln\frac{b}{a}, \quad R_{l2} = \frac{1}{2\pi\sigma_2}\ln\frac{c}{b}$$

串联总漏电阻：

> $$\boxed{R = R_{l1} + R_{l2} = \frac{1}{2\pi}\left(\frac{\ln(b/a)}{\sigma_1} + \frac{\ln(c/b)}{\sigma_2}\right) \quad \Omega/\text{m}}$$

**电容**：两层介质相当于两个串联电容，每层单位长度电容为：

$$C_1 = \frac{2\pi\varepsilon_1}{\ln(b/a)}, \quad C_2 = \frac{2\pi\varepsilon_2}{\ln(c/b)}$$

串联总电容：

$$\frac{1}{C} = \frac{1}{C_1}+\frac{1}{C_2} = \frac{\ln(b/a)}{2\pi\varepsilon_1}+\frac{\ln(c/b)}{2\pi\varepsilon_2}$$

> $$\boxed{C = \frac{2\pi}{\dfrac{\ln(b/a)}{\varepsilon_1}+\dfrac{\ln(c/b)}{\varepsilon_2}} \quad \text{F/m}}$$

> **物理理解**：电场的分布由 $\sigma_1,\sigma_2$ 决定（恒定电场按电导率分配电流），而电容由 $\varepsilon_1,\varepsilon_2$ 决定（静电场按介电常数分配电位）。只有当 $\varepsilon_1/\sigma_1 = \varepsilon_2/\sigma_2$ 时，静电比拟完全成立，电容和漏电导才满足 $G = \sigma C/\varepsilon$ 关系。
