# 例 3.2.2 半球形接地器的接地电阻

## 题目
计算半球形接地器的接地电阻。设大地电导率为 $\sigma$，接地器（半球）半径为 $a$，流过接地器的电流为 $I$。

---

## 方法一：直接法

接地器为半球体，埋于大地表面。电流从半球表面向大地扩散，在距球心距离为 $r$ 的半球面上（面积 $2\pi r^2$），由 $\nabla\cdot\vec{J}=0$ 及球对称性，电流密度均匀分布：

$$\vec{J} = \vec{e}_r\frac{I}{2\pi r^2}$$

由 $\vec{J}=\sigma\vec{E}$，得电场强度：

$$\vec{E} = \frac{\vec{J}}{\sigma} = \vec{e}_r\frac{I}{2\pi\sigma r^2}$$

接地器表面（$r=a$）相对无穷远处（大地参考零电位）的电位差即为接地器的电压：

$$U = \int_a^{\infty} E\,dr = \frac{I}{2\pi\sigma}\int_a^{\infty}\frac{dr}{r^2} = \frac{I}{2\pi\sigma}\cdot\frac{1}{a} = \frac{I}{2\pi\sigma a}$$

所以接地电阻为：

> $$\boxed{R = \frac{U}{I} = \frac{1}{2\pi\sigma a}}$$

---

## 方法二：静电比拟法

均匀介质（介电常数 $\varepsilon$）中孤立导体球的电容为：

$$C = 4\pi\varepsilon a$$

利用[[3.2.2_恒定电场与静电场的比拟|静电比拟]] $G/C = \sigma/\varepsilon$，得孤立球（全球）在均匀导电介质中的电导：

$$G_{球} = \frac{\sigma}{\varepsilon}\cdot 4\pi\varepsilon a = 4\pi\sigma a$$

由于接地器只有下半球在大地中，电流只在下半空间（半球）流动，因此：

$$G_{半球} = \frac{1}{2}G_{球} = 2\pi\sigma a$$

则接地电阻为：

> $$\boxed{R = \frac{1}{G_{半球}} = \frac{1}{2\pi\sigma a}}$$

两种方法结果一致。
