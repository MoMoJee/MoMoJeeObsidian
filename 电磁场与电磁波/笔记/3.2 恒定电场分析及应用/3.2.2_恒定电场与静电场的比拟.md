# 3.2.2 恒定电场与静电场的比拟

恒定电场与静电场的比拟是一种求解场的方法。如果两种场在特定条件下场方程形式相同、边界形状相同且边界条件等效，其解具有相同的形式。求解一种场后，通过对应的物理量替换即可得到另一种场的解。

==对应关系列表==：

- ==基本方程的对应==：
  静电场（无电荷区域）：$\nabla \cdot \vec{D} = 0$，$\nabla \times \vec{E} = 0$
  恒定电场（电源外）：$\nabla \cdot \vec{J} = 0$，$\nabla \times \vec{E} = 0$

- ==本构关系的对应==：
  静电场：$\vec{D} = \varepsilon \vec{E}$
  恒定电场：$\vec{J} = \sigma \vec{E}$

- ==位函数与拉普拉斯方程==：
  两者均满足 $\vec{E} = -\nabla \varphi$ 及 $\nabla^2 \varphi = 0$

- ==物理量的对应代换==：
  - 电场强度 $\vec{E}$ $\longleftrightarrow$ 电场强度 $\vec{E}$
  - 电位移矢量 $\vec{D}$ $\longleftrightarrow$ 电流密度 $\vec{J}$
  - 电位 $\varphi$ $\longleftrightarrow$ 电位 $\varphi$
  - 电荷量 $q$ $\longleftrightarrow$ 电流 $I$
  - 介电常数 $\varepsilon$ $\longleftrightarrow$ 电导率 $\sigma$
  - 电容 $C$ $\longleftrightarrow$ 电导 $G$
