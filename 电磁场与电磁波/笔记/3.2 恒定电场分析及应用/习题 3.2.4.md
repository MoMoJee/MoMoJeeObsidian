# 习题 3.2.4 半导体薄膜中同心圆形电极之间的电阻

## 题目
设有一厚度为 $h$ 的半导体薄膜，其上带有半径分别为 $a$ 和 $b$ 的同心理想导电电极（$b \geq a \geq h$），半导体材料薄膜沉积在绝缘体上，材料电导率为 $\sigma$。求两电极之间的电阻。

---

## 解答

### 建立物理模型

由于 $a \geq h$（最小的圆弧半径已远大于薄膜厚度），电流在薄膜平面内沿径向 $\vec{e}_\rho$ 方向流动，在厚度方向均匀分布，且薄膜上下面均为绝缘界面（不漏电），因此问题退化为==二维平面径向电流问题==，但截面面积需乘以厚度 $h$。

### 求解过程

设两电极间流过的总电流为 $I$（从内电极向外电极）。

在半径 $\rho$ 处，电流通过面积 $2\pi\rho \cdot h$（圆周长 $\times$ 薄膜厚度），由 $\nabla\cdot\vec{J}=0$：

$$\vec{J} = \vec{e}_\rho\frac{I}{2\pi\rho h}$$

由欧姆定律 $\vec{J}=\sigma\vec{E}$：

$$\vec{E} = \frac{\vec{J}}{\sigma} = \vec{e}_\rho\frac{I}{2\pi\sigma\rho h}$$

两电极间的电压：

$$U = \int_a^b E\,d\rho = \int_a^b\frac{I}{2\pi\sigma\rho h}\,d\rho = \frac{I}{2\pi\sigma h}\ln\frac{b}{a}$$

两电极间的电阻：

> $$\boxed{R = \frac{U}{I} = \frac{1}{2\pi\sigma h}\ln\frac{b}{a}}$$

> **与同轴线漏电阻的对比**：同轴线单位长度绝缘电阻为 $R_1 = \frac{1}{2\pi\sigma}\ln\frac{b}{a}$（参见[[例 3.2.1|同轴线绝缘电阻]]），而本题薄膜中的电阻相当于把单位长度换成了实际厚度 $h$，二者形式完全对应。这体现了恒定电场分析方法的统一性：只要电场具有柱对称性且电流只在径向流动，结构就只相差一个有效长度因子。

---

## 方法二：静电比拟法

本题的几何形状——两个同心圆形电极，夹着厚度为 $h$ 的介质层——与一个高度为 $h$ 的同轴圆柱电容器完全相同。因此可以直接套用[[例 3.2.1#方法二：静电比拟法|静电比拟关系]]：

$$RC = \frac{\varepsilon}{\sigma}$$

**第一步：求对应电容器的电容**

高度为 $h$、内径 $a$、外径 $b$ 的同轴圆柱电容器，电容为（见[[公式速查手册|电容公式表]]）：

$$C = \frac{2\pi\varepsilon h}{\ln(b/a)}$$

**第二步：由比拟关系直接求 $R$**

$$R = \frac{\varepsilon}{\sigma C} = \frac{\varepsilon}{\sigma}\cdot\frac{\ln(b/a)}{2\pi\varepsilon h} = \frac{\ln(b/a)}{2\pi\sigma h}$$

与方法一结果完全一致。

> **为什么这里可以用静电比拟法？**
> 静电比拟法的前提是：电场分布形状完全相同的条件下，$\varepsilon$ 与 $\sigma$ 扮演同等角色。本题的恒定电场 $\vec{E}$ 和对应电容器充电后的静电场 $\vec{E}$，都具有相同的柱坐标对称性，且两者的边界条件（理想导体电极）形式一致，因此比拟关系成立。
