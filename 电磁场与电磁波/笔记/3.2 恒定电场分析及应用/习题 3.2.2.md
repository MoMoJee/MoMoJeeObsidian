# 习题 3.2.2 均匀介质中两导体球之间的电阻

## 题目
在电导率为 $\sigma$ 的无限大均匀介质内，有两个半径分别为 $R_1$ 和 $R_2$ 的理想导体小球，两小球之间的距离为 $d$（设 $d \gg R_1$，$d \gg R_2$），试求两个小导体球面之间的电阻（只需求一级近似解）。

---

## 解答

### 思路：静电比拟 + 孤立球近似

由于 $d \gg R_1, R_2$（两球间距远大于各自半径），**一级近似**下可以忽略两球之间的电场相互影响，即认为每个球周围的电场与该球孤立存在时完全相同。

**静电比拟**：均匀介质（介电常数 $\varepsilon$）中[[3.1.3_导体系统的电容#^4523c6|孤立导体球的电容]]为：

$$C_i = 4\pi\varepsilon R_i$$

由[[3.2.2_恒定电场与静电场的比拟|静电比拟关系]] $G/C = \sigma/\varepsilon$，孤立导体球在均匀导电介质中的电导为：

$$G_i = \frac{\sigma}{\varepsilon} \cdot 4\pi\varepsilon R_i = 4\pi\sigma R_i$$

对应的"接地电阻"（球面到无穷远处的电阻）为：

$$R_{接地,i} = \frac{1}{G_i} = \frac{1}{4\pi\sigma R_i}$$

### 串联

从球1的表面出发，电流流经无穷远的大介质再回到球2的表面。两个接地电阻串联：

$$R = R_{接地,1} + R_{接地,2} = \frac{1}{4\pi\sigma R_1} + \frac{1}{4\pi\sigma R_2}$$

> $$\boxed{R = \frac{1}{4\pi\sigma}\left(\frac{1}{R_1} + \frac{1}{R_2}\right)}$$

> **物理图像**：电流从球1表面出发，向周围介质中向外扩散（辐射状），到达"无穷远"后又向球2方向收敛。两段路径的电阻相加构成总电阻。由于 $d \gg R_1, R_2$，球1和球2之间介质路径的大部分电阻集中在每个球的近旁，球间中间段的电阻相比之下可以忽略，这也是该近似成立的原因。
