# 【考试难点】两块无限大接地导体平板间的电位场求解

## 1. 问题描述
两块无限大接地导体平板分别置于  = 0$ 和  = a$ 处。在两板之间的  = b$ 处，有一面密度为 $\rho_{S0}$ 的均匀面电荷分布，周围空间介电常数假定为真空的 $\varepsilon_0$。求两导体平板之间的空间内的电位 $\varphi$ 分布和电场强度 $\vec{E}$ 分布。

## 2. 求解思路与物理模型
由于两导体板无限大，且在 $ 与 $ 方向上没有结构变化，电位仅依赖于 $ 坐标。这个问题是一维模型。
在两块接地导体板之间，除  = b$ 的面电荷外，其余区域皆无自由电荷。因此，可以将区域划分为两部分，分别求解该区域内的一维鎈普拉斯方程：
- **区域一**： < x < b$
- **区域二**： < x < a$

在一维情况下，拉普拉斯方程 $\nabla^2 \varphi = 0$ 退化为对 $ 的二阶常微分方程：$\frac{\mathrm{d}^2 \varphi}{\mathrm{d} x^2} = 0$。我们需要通过求解该方程并在分界面  = b$ 与导体板处使用边界条件确定积分常数。

## 3. 详细求解步骤

### 第一步：写出电位的一般解形式
分别对两个区域的拉普拉斯方程进行两次积分，得到线性方程形式：
File
\frac{\mathrm{d}^2 \varphi_1(x)}{\mathrm{d} x^2} = 0 \quad \Longrightarrow \quad \varphi_1(x) = C_1 x + D_1 \quad (0 < x < b)
File
File
\frac{\mathrm{d}^2 \varphi_2(x)}{\mathrm{d} x^2} = 0 \quad \Longrightarrow \quad \varphi_2(x) = C_2 x + D_2 \quad (b < x < a)
File
其中，, D_1, C_2, D_2$ 是四个待定的未知积分常数。

### 第二步：分析边界条件并列出方程
要解出这四个变量，必须列出四个方程。
1. **导体板接地条件（电位为零）**：
   在  = 0$ 处，导体板接地，因此 $\varphi_1(0) = 0$。代入得： = 0$
   在  = a$ 处，导体板接地，因此 $\varphi_2(a) = 0$。代入得： a + D_2 = 0$

2. **面电荷处的电位连续性条件**：
    = b$ 处只是一层极薄的面电荷，两侧电位必须连续，即 $\varphi_1(b) = \varphi_2(b)$。
   代入解得： b + D_1 = C_2 b + D_2$

3. **面电荷处的电场法向跃变条件**：
   电场强度的法向分量在穿过带有面电荷分布边界时存在跃变。边界条件方程为：
   File
   D_{2n} - D_{1n} = \rho_S \quad \Longrightarrow \quad \varepsilon_0 E_2(x) - \varepsilon_0 E_1(x) = \rho_{S0}
   File
   根据电场强度定义 $\vec{E} = -\nabla\varphi$，在一维情况中 (x) = -\frac{\partial \varphi}{\partial x}$。故在  = b$ 处：
   File
   E_1(x) = - \frac{\partial \varphi_1(x)}{\partial x} = -C_1
   File
   File
   E_2(x) = - \frac{\partial \varphi_2(x)}{\partial x} = -C_2
   File
   代入上式得：$\varepsilon_0 (-C_2) - \varepsilon_0 (-C_1) = \rho_{S0}$
   整理后得到第四个方程：
   File
   C_2 - C_1 = -\frac{\rho_{S0}}{\varepsilon_0}
   File

### 第三步：求解常数并代回原式
联立上述已知的条件：
- 由  = 0$ 及  a + D_2 = 0$，知道  = -C_2 a$。
- 将 , D_2$ 代入连续性方程  b = C_2 b - C_2 a = C_2 (b - a)$。
- 将  = C_2 \frac{b - a}{b}$ 代入跃变方程：
  File
  C_2 - C_2 \frac{b - a}{b} = -\frac{\rho_{S0}}{\varepsilon_0}
  File
  File
  C_2 \cdot \frac{a}{b} = -\frac{\rho_{S0}}{\varepsilon_0} \quad \Longrightarrow \quad C_2 = -\frac{\rho_{S0} b}{\varepsilon_0 a}
  File
- 进而求得：
  File
  C_1 = C_2 \frac{b - a}{b} = -\frac{\rho_{S0} (b - a)}{\varepsilon_0 a} = \frac{\rho_{S0} (a - b)}{\varepsilon_0 a}
  File
  File
  D_2 = -C_2 a = \frac{\rho_{S0} b}{\varepsilon_0}

## 4. 最终结论
将求出的积分常数代回到初始假设的解中，得到完整的电位分布函数：
File
\varphi_1(x) = \frac{\rho_{S0}(a-b)}{\varepsilon_0 a} x \quad (0 \leq x \leq b)
File
File
\varphi_2(x) = \frac{\rho_{S0} b}{\varepsilon_0 a} (a-x) \quad (b \leq x \leq a)
File

对上述电位求负梯度运算即为空间电场强度 $\vec{E} = -\nabla\varphi$，由于只在 $ 方向有变化：

\vec{E}_1(x) = - \vec{e}_x \frac{\mathrm{d} \varphi_1(x)}{\mathrm{d} x} = - \vec{e}_x \frac{\rho_{S0}(a-b)}{\varepsilon_0 a} \quad (0 \leq x < b)

File
\vec{E}_2(x) = - \vec{e}_x \frac{\mathrm{d} \varphi_2(x)}{\mathrm{d} x} = \vec{e}_x \frac{\rho_{S0} b}{\varepsilon_0 a} \quad (b < x \leq a)
