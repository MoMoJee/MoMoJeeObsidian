# 3.1.5 静电力

对于电荷分布复杂的带电系统，采用库仑定律计算静电力存在过程繁琐等困难。在此类情况下，可通过虚位移法计算静电力。

==虚位移法：假设第 $i$ 个带电导体在电场力 $F _ { i }$ 的作用下发生位移 $\mathrm { d } g _ { i }$ ，则电场力做功为 $\mathrm { d } A = F _ { i } \mathrm { d } g _ { i }$ ，系统的静电能量改变为 $\mathrm { d } W _ { e }$ 。==

根据能量守恒定律，系统的功能关系为

$$
\mathrm {d} W _ {S} = F _ {i} \mathrm {d} g _ {i} + \mathrm {d} W _ {e}
$$

其中 $\mathrm { d } W _ { S }$ 为外电源所提供的能量。

在具体计算中，根据物理条件可假定各带电导体的电位不变，或假定各带电导体的电荷不变。

## 1. 各带电导体的电位不变

当带电导体与外电压源连接时，系统的电位维持在一个常数。外电压源向系统提供的能量为

$$
\mathrm {d} W _ {S} = \sum_ {i = 1} ^ {N} \mathrm {d} (q _ {i} \varphi_ {i}) = \sum_ {i = 1} ^ {N} \varphi_ {i} \mathrm {d} q _ {i}
$$

系统所改变的静电能量为

$$
\mathrm { d } W _ { e } = \frac { 1 } { 2 } \sum _ { i = 1 } ^ { N } \mathrm { d } ( q _ { i } \varphi _ { i } ) = \frac { 1 } { 2 } \sum _ { i = 1 } ^ { N } \varphi _ { i } \mathrm { d } q _ { i }
$$

通过合并能量转换公式，得到

$$
\mathrm { d } W _ { S } = 2 \mathrm { d } W _ { e } \quad \Longrightarrow \quad F _ { i } \mathrm { d } g _ { i } = \mathrm { d } W _ { e } \quad \Longrightarrow \quad F _ { i } = \frac { \partial W _ { e } } { \partial g _ { i } } \Bigg | _ { \varphi \text { 不变} }
$$

## 2. 各带电导体的电荷不变

当带电体不与外界交换电荷时，外部不提供能量， $\mathrm { d } W _ { S } = 0$ 。此时

$$
F _ {i} \mathrm {d} g _ {i} = - \mathrm {d} W _ {e} \quad \Longrightarrow \quad F _ {i} = - \frac {\partial W _ {e}}{\partial g _ {i}} \Bigg | _ {q \text { 不变}}
$$

式中的负号表明电场力做功的能量源于系统的静电能量。

**例：有一平行金属板电容器，极板面积为 $l \times b$ ，板间距离为 $d$ 。一块宽度为 $b$、厚度为 $d$ 、介电常数为 $\varepsilon$ 的介质片部分插入两极板之间。设极板间外加电压为 $U _ { 0 }$ ，忽略边缘效应计算介质片所受的静电力。**

解：根据电容器的串并联特性，平行板电容器的电容为两部分并联的等效电容

$$
C = \varepsilon_ {0} \frac {(l - x) b}{d} + \varepsilon \frac {b x}{d}
$$

电容器内的电场能量为

$$
W _ {e} = \frac {1}{2} C U _ {0} ^ {2} = \frac {b U _ {0} ^ {2}}{2 d} [ \varepsilon_ {0} (l - x) + \varepsilon x ]
$$

在保持电压 $U _ { 0 }$ 不变的情况下，应用公式 $F _ { i } = \frac { \partial W _ { e } } { \partial g _ { i } }$ ；可求得介质片受到的静电力（沿 $x$ 轴方向）为

$$
F _ {x} = \frac {\partial W _ {e}}{\partial x} \Bigg | _ {U _ {0} \text { 不变}} = \frac {b (\varepsilon - \varepsilon_ {0}) U _ {0} ^ {2}}{2 d}
$$

若应用条件 $F _ { i } = - \frac { \partial W _ { e } } { \partial g _ { i } }$ 计算，在保持总电荷 $q$ 不变时，电场能量为

$$
W _ {e} = \frac {q ^ {2}}{2 C} = \frac {d q ^ {2}}{2 b [ \varepsilon_ {0} (l - x) + \varepsilon x ]}
$$

对此求导得到力的表达式

$$
F _ { x } = - \frac { \partial W _ { e } } { \partial x } \Bigg | _ { q \text { 不变} } = \frac { d ( \varepsilon - \varepsilon _ { 0 } ) q ^ { 2 } } { 2 b [ \varepsilon _ { 0 } ( l - x ) + \varepsilon x ] ^ { 2 } }
$$

代入 $q = C U _ { 0 } = \frac { b U _ { 0 } } { d } [ \varepsilon _ { 0 } ( l - x ) + \varepsilon x ]$ ，化简后结果相同

$$
F _ { x } = \frac { b ( \varepsilon - \varepsilon _ { 0 } ) U _ { 0 } ^ { 2 } } { 2 d }
$$
