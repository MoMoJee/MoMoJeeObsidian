# 3.1.4 静电场的能量与电容储能

静电场的基本特征是对电荷有作用力，这表明静电场具有能量。

==静电场能量来源于建立电荷系统的过程中外源提供的能量。==

带电系统经过从没有电荷分布到最终电荷分布的建立（或充电）过程时，外加电源必须克服电荷之间的相互作用力作功。

当充电过程进行得足够缓慢时，充电过程中外加电源所作的总功将转换成电场能量，即外加电源在此电场建立过程中所作的总功在数值上等于电场能量。

## 1. 静电场的能量

设系统从零开始充电，最终带电量为 $q$ 、电位为 $\varphi$ 。

充电过程中某一时刻的电荷量为 $\alpha q$ 、电位为 $\alpha \varphi$ 。 ($0 \le \alpha \le 1$)

当 $\alpha$ 增加为 $(\alpha + \mathrm{d}\alpha)$ 时，外电源作功为：$\alpha \varphi (q \, \mathrm {d} \alpha)$ 。

对 $\alpha$ 从 0 到 1 积分，得到外电源所作的总功为

$$
\int_ {0} ^ {1} \alpha q \varphi d \alpha = \frac {1}{2} q \varphi
$$

根据能量守恒定律，此功即为电量为 $q$ 的带电体具有的电场能量 $W _ { e }$ ，即：

$$
W _ { e } = \frac { 1 } { 2 } q \varphi
$$

对于电荷体密度为 $\rho$ 的体分布电荷，体积元 $\mathrm{d}V$ 中的电荷 $\rho \mathrm{d}V$ 具有的电场能量为

$$
\mathrm {d} W _ {e} = \frac {1}{2} \rho \varphi \mathrm {d} V
$$

体分布电荷的电场能量为

$$
W _ {e} = \frac {1}{2} \int_ {V} \rho \varphi \mathrm {d} V
$$

对于面分布电荷，电场能量为

$$
W _ {e} = \frac {1}{2} \int_ {S} \rho_ {S} \varphi d S
$$

对于多导体组成的带电系统，则有

$$
W _ {e} = \frac {1}{2} \sum_ {i} \oint_ {S _ {i}} \rho_ {S _ {i}} \varphi_ {i} \mathrm {d} S = \frac {1}{2} \sum_ {i} \varphi_ {i} \oint_ {S _ {i}} \rho_ {S _ {i}} \mathrm {d} S = \frac {1}{2} \sum_ {i} \varphi_ {i} q _ {i}
$$

式中：
$q _ {i}$ —— 第 $i$ 个导体所带的电荷；
$\varphi_ {i}$ —— 第 $i$ 个导体的电位。

## 2. 电场能量密度==**期中考要考**==

![[Pasted image 20260413211056.jpg]]


从场的观点来看，静电场的能量分布于电场所在的各处空间。

电场能量密度为：

$$
w _ { e } = \frac { 1 } { 2 } \vec { D } \cdot \vec { E }
$$

电场的总能量可以通过体积分求出（积分区域为电场所在的所讨论空间）：

$$
W _ { e } = \frac { 1 } { 2 } \int _ { V } \vec { D } \cdot \vec { E } \mathrm { d } V
$$

对于线性、各向同性介质，电场能量密度为：

$$
w _ {e} = \frac {1}{2} \vec {D} \cdot \vec {E} = \frac {1}{2} \varepsilon \vec {E} \cdot \vec {E} = \frac {1}{2} \varepsilon E ^ {2}
$$

总能量为：

$$
W _ {e} = \frac {1}{2} \int_ {V} \vec {D} \cdot \vec {E} \mathrm {d} V = \frac {1}{2} \int_ {V} \varepsilon \vec {E} \cdot \vec {E} \mathrm {d} V = \frac {1}{2} \int_ {V} \varepsilon E ^ {2} \mathrm {d} V
$$

电场能量公式的推证过程如下（==此证明具有极高的考试价值，详细的分步剖析请见独立笔记：== [[【考试难点】_静电场总能量公式推导]]）：

$$
\begin{array}{r l}
W _ {e} &= \frac {1}{2} \int_ {V} \rho \varphi \mathrm {d} V \\
&= \frac {1}{2} \int_ {V} (\nabla \cdot \vec {D}) \varphi \mathrm {d} V \\
&= \frac {1}{2} \int_ {V} [ \nabla \cdot (\varphi \vec {D}) - \nabla \varphi \cdot \vec {D} ] \mathrm {d} V \\
&= \frac {1}{2} \oint_ {S} \varphi \vec {D} \cdot \mathrm {d} \vec {S} + \frac {1}{2} \int_ {V} \vec {E} \cdot \vec {D} \mathrm {d} V
\end{array}
$$

因为电荷分布在有限区域内，==当闭合面 $S$ 扩大时，电位 $\varphi$ 和电位移密度 $\vec{D}$ 按如下规律变化：==

$$
\varphi \propto \frac {1}{R}, \quad D \propto \frac {1}{R ^ {2}}
$$

面积分项趋近于零：

$$
\oint _ { S } \varphi \vec { D } \cdot \mathrm { d } \vec { S } \propto \oint _ { S } \frac { 1 } { R } \cdot \frac { 1 } { R ^ { 2 } } \mathrm { d } S \propto \frac { 1 } { R } \to 0
$$

> 在掌握了上述两种静电场能量的计算体系（体电荷积分与全空间能量密度积分）后，我们需要通过经典模型来验证两者的统一性。
> **例题：半径为 $a$ 的球形空间内均匀分布有电荷体密度为 $\rho$ 的电荷，求解静电场能量。**
> （==本题作为期中常考题型，两种解法的严格步骤详见独立笔记：== [[【考试难点】_均匀带电球体的静电场能量计算]]）

解（简述）：

**方法一：利用场能量密度公式 $W _ { e } = \frac { 1 } { 2 } \int _ { V } \vec { D } \cdot \vec { E } \mathrm { d } V$ 计算。**

根据高斯定理求得电场强度

$$
\vec {E} _ {1} = \vec {e} _ {r} \frac {\rho r}{3 \varepsilon_ {0}} \quad (r \le a)
$$

$$
\vec {E} _ {2} = \vec {e} _ {r} \frac {\rho a ^ {3}}{3 \varepsilon_ {0} r ^ {2}} \quad (r > a)
$$

故总能量为

$$
W _ { e } = \frac { 1 } { 2 } \int _ { V _ { 1 } } \varepsilon _ { 0 } E _ { 1 } ^ { 2 } \mathrm { d } V + \frac { 1 } { 2 } \int _ { V _ { 2 } } \varepsilon _ { 0 } E _ { 2 } ^ { 2 } \mathrm { d } V
$$

$$
= \frac {1}{2} \varepsilon_ {0} \left( \int_ {0} ^ {a} \frac {\rho^ {2} r ^ {2}}{9 \varepsilon_ {0} {} ^ {2}} \cdot 4 \pi r ^ {2} \mathrm {d} r + \int_ {a} ^ {\infty} \frac {\rho^ {2} a ^ {6}}{9 \varepsilon_ {0} {} ^ {2} r ^ {4}} \cdot 4 \pi r ^ {2} \mathrm {d} r \right) = \frac {4 \pi}{15 \varepsilon_ {0}} \rho^ {2} a ^ {5}
$$

**方法二：利用电荷电位积分公式 $W _ { e } = \frac { 1 } { 2 } \int _ { V } \rho \varphi \mathrm { d } V$ 计算。**

先求解电位分布

$$
\begin{array}{l}
\varphi_ {1} = \int_ {r} ^ {a} \vec {E} _ {1} \cdot \mathrm {d} \vec {r} + \int_ {a} ^ {\infty} \vec {E} _ {2} \cdot \mathrm {d} \vec {r} \\
= \int_ {r} ^ {a} \frac {\rho r}{3 \varepsilon_ {0}} \mathrm {d} r + \int_ {a} ^ {\infty} \frac {\rho a ^ {3}}{3 \varepsilon_ {0} r ^ {2}} \mathrm {d} r \\
= \frac {\rho}{2 \varepsilon_ {0}} \left(a ^ {2} - \frac {r ^ {2}}{3}\right) \qquad (r \le a)
\end{array}
$$

通过积分求解

$$
\frac { 1 } { 2 } \int _ { V } \rho \varphi _ { 1 } \mathrm { d } V = \frac { 1 } { 2 } \cdot \frac { \rho ^ { 2 } } { 2 \varepsilon _ { 0 } } \int _ { 0 } ^ { a } \left( a ^ { 2 } - \frac { r ^ { 2 } } { 3 } \right) 4 \pi r ^ { 2 } \mathrm { d } r = \frac { 4 \pi } { 15 \varepsilon _ { 0 } } \rho ^ { 2 } a ^ { 5 }
$$
