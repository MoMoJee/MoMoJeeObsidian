# 习题 3.4.3 两个电位函数与惟一性定理的适用性

## 题目

有两个电位函数 $\varphi_1 = y$ 和 $\varphi_2 = y + e^x\sin y$，判断以下等式是否成立，并回答所提出的问题：

1. 是否有 $\nabla^2\varphi_1 = 0$ 和 $\nabla^2\varphi_2 = 0$；
2. 在 $y=0$ 处，是否有 $\varphi_1 = 0$ 和 $\varphi_2 = 0$；
3. 在 $y=\pi$ 处，是否有 $\varphi_1 = \pi$ 和 $\varphi_2 = \pi$；
4. [[3.4.2_静电场的惟一性定理（期末喜欢考证明）|惟一性定理]]在这里是否适用？

---

## (1) 是否满足拉普拉斯方程

**对 $\varphi_1 = y$：**

$$\nabla^2\varphi_1 = \frac{\partial^2 y}{\partial x^2} + \frac{\partial^2 y}{\partial y^2} = 0 + 0 = 0$$

**结论：** $\nabla^2\varphi_1 = 0$ **成立**。

---

**对 $\varphi_2 = y + e^x\sin y$，分别计算各方向二阶偏导：**

$$\frac{\partial\varphi_2}{\partial x} = e^x\sin y \;\Rightarrow\; \frac{\partial^2\varphi_2}{\partial x^2} = e^x\sin y$$

$$\frac{\partial\varphi_2}{\partial y} = 1 + e^x\cos y \;\Rightarrow\; \frac{\partial^2\varphi_2}{\partial y^2} = -e^x\sin y$$

因此：

$$\nabla^2\varphi_2 = e^x\sin y + (-e^x\sin y) = 0$$

**结论：** $\nabla^2\varphi_2 = 0$ **成立**。

两个电位函数都满足拉普拉斯方程，都是自由空间中可能的静电场电位分布。

---

## (2) 在 $y = 0$ 处的值

$$\varphi_1\big|_{y=0} = 0 \quad \checkmark$$

$$\varphi_2\big|_{y=0} = 0 + e^x\sin 0 = e^x \cdot 0 = 0 \quad \checkmark$$

**结论：** 在 $y=0$ 处，$\varphi_1 = 0$ 和 $\varphi_2 = 0$ **均成立**。

---

## (3) 在 $y = \pi$ 处的值

$$\varphi_1\big|_{y=\pi} = \pi \quad \checkmark$$

$$\varphi_2\big|_{y=\pi} = \pi + e^x\sin\pi = \pi + e^x\cdot 0 = \pi \quad \checkmark$$

**结论：** 在 $y=\pi$ 处，$\varphi_1 = \pi$ 和 $\varphi_2 = \pi$ **均成立**。

---

## (4) 惟一性定理是否适用？

### 现象分析

从 (1)(2)(3) 的结论来看，$\varphi_1$ 和 $\varphi_2$ 同时满足：
- $\nabla^2\varphi = 0$（在无源区域内）；
- $\varphi = 0$（在边界 $y=0$ 处）；
- $\varphi = \pi$（在边界 $y=\pi$ 处）。

两个不同的函数满足相同的方程和相同的边界条件，这似乎与[[3.4.2_静电场的惟一性定理（期末喜欢考证明）|惟一性定理]]矛盾——但实际上并不矛盾，原因在于**边界条件不完整**。

### 关键原因

考虑求解域是无限长带状区域 $\{(x,y) \mid -\infty < x < +\infty,\; 0 \leq y \leq \pi\}$。这个区域在 $x$ 方向延伸到无穷远，除了上下两条边界 $y=0$ 和 $y=\pi$ 之外，还存在 $x\to\pm\infty$ 方向的"无穷远边界"。

[[3.4.2_静电场的惟一性定理（期末喜欢考证明）|惟一性定理]]要求在求解域的**全部边界**上给定边界条件（Dirichlet、Neumann 或混合型）。本题仅给定了 $y=0$ 和 $y=\pi$ 两条有限边界上的条件，**没有给定 $x\to\pm\infty$ 处的自然边界条件**，因此边界条件是不完整的，导致解不唯一。

### 具体说明

- $\varphi_1 = y$：在整个带状域内有界，当 $x\to\pm\infty$ 时，$\varphi_1$ 保持有界（仅与 $y$ 有关）。
- $\varphi_2 = y + e^x\sin y$：当 $x\to+\infty$ 时，$e^x\to\infty$，$\varphi_2$ 无界发散。

若在边界条件中**额外补充自然边界条件：当 $x\to\pm\infty$ 时，$\varphi$ 保持有界（不发散）**，则：

- $\varphi_2$ 因为 $x\to+\infty$ 时发散，**不满足**这个自然边界条件，被排除；
- $\varphi_1 = y$ 满足所有边界条件，是**唯一解**。

### 结论

> **[[3.4.2_静电场的惟一性定理（期末喜欢考证明）|惟一性定理]]适用**，但前提是必须给出**完整的边界条件**，包括在无界域中 $x\to\pm\infty$ 处的自然边界条件（解在无穷远处有界）。
>
> 本题之所以出现两个满足方程和部分边界条件的解，正是因为 $y=0$ 和 $y=\pi$ 这两个条件**不构成完整边界条件**——没有约束 $x\to\pm\infty$ 方向的行为。
>
> 一旦补充"解在整个域内有界"的自然边界条件，$\varphi_1 = y$ 就是满足所有条件的唯一解，惟一性定理完全成立。
