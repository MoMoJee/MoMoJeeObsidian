# 例 3.3.6 两同轴平行圆线圈之间的互感（远场近似）

## 题目

两个互相平行且共轴的圆线圈，半径分别为 $a_1$ 和 $a_2$，中心相距 $d$，设 $a_1 \ll d$（或 $a_2 \ll d$）。求两线圈之间的互感 $M$。

---

## 方法一：诺依曼公式 + 远场近似

### 第一步：建立几何关系

线圈 $C_1$（半径 $a_1$，上方，距原点 $d/2$）和 $C_2$（半径 $a_2$，下方）。设 $C_1$ 上的线元 $d\vec{l}_1 = a_1 d\phi_1$，$C_2$ 上的线元 $d\vec{l}_2 = a_2 d\phi_2$。

两线元之间的夹角 $\theta = \phi_2 - \phi_1$，两线元之间的距离：

$$R = |\vec{r}_2 - \vec{r}_1| = \sqrt{d^2 + a_1^2 + a_2^2 - 2a_1 a_2\cos(\phi_2-\phi_1)}$$

### 第二步：代入诺依曼公式

[[3.3.3_电感|诺依曼公式]]：

$$M = \frac{\mu_0}{4\pi}\oint_{C_1}\oint_{C_2}\frac{d\vec{l}_2\cdot d\vec{l}_1}{|\vec{r}_2-\vec{r}_1|}$$

$d\vec{l}_1\cdot d\vec{l}_2 = a_1 a_2\cos(\phi_2-\phi_1)\,d\phi_1\,d\phi_2$，对 $\phi_1$ 积分后（利用对称性，令 $\theta = \phi_2 - \phi_1$）：

$$M = \frac{\mu_0 a_1 a_2}{2}\int_0^{2\pi}\frac{\cos\theta\,d\theta}{\sqrt{d^2+a_1^2+a_2^2-2a_1 a_2\cos\theta}}$$

一般情况下此积分只能用椭圆积分表示，**下面利用 $d \gg a_1$ 进行近似**。

### 第三步：远场近似展开

提取 $\sqrt{d^2+a_1^2+a_2^2}$：

$$\left[d^2+a_1^2+a_2^2-2a_1 a_2\cos\theta\right]^{-1/2} \approx \frac{1}{\sqrt{d^2+a_2^2}}\left[1+\frac{a_1 a_2\cos\theta}{d^2+a_2^2}\right]$$

（利用 $(1-\varepsilon)^{-1/2}\approx 1+\varepsilon/2$，忽略 $a_1^2/(d^2+a_2^2)$ 等高阶小量）

代入互感积分：

$$M \approx \frac{\mu_0 a_1 a_2}{2\sqrt{d^2+a_2^2}}\int_0^{2\pi}\left[1+\frac{a_1 a_2\cos\theta}{d^2+a_2^2}\right]\cos\theta\,d\theta$$

- $\int_0^{2\pi}\cos\theta\,d\theta = 0$（零次项贡献为零）
- $\int_0^{2\pi}\cos^2\theta\,d\theta = \pi$

所以：

$$M \approx \frac{\mu_0 a_1 a_2}{2\sqrt{d^2+a_2^2}}\cdot\frac{a_1 a_2\pi}{d^2+a_2^2} = \frac{\mu_0\pi a_1^2 a_2^2}{2(d^2+a_2^2)^{3/2}}$$

> $$\boxed{M = \frac{\mu_0\pi a_1^2 a_2^2}{2(d^2+a_2^2)^{3/2}}}$$

---

## 方法二：利用例 3.3.1 的磁偶极子远场结果（更简洁）

在 $d \gg a_1$ 的条件下，线圈 $C_1$ 相当于一个[[例 3.3.1|磁偶极子]]，磁矩 $p_m = I_1\pi a_1^2$。

由例 3.3.1 的结果，小圆环的远场矢量磁位为：

$$\vec{A}_1 = \vec{e}_\phi\frac{\mu_0}{4\pi}\cdot\frac{\pi a_1^2 I_1}{R^2}\sin\theta$$

在 $C_2$ 所在平面上（半径 $a_2$ 处），$\vec{A}_1$ 的大小为常数（对称性），取 $R = \sqrt{d^2+a_2^2}$，$\sin\theta = \dfrac{a_2}{\sqrt{d^2+a_2^2}}$：

$$A_1 = \frac{\mu_0\pi a_1^2 I_1}{4\pi(d^2+a_2^2)}\cdot\frac{a_2}{\sqrt{d^2+a_2^2}} = \frac{\mu_0 a_1^2 I_1 a_2}{4(d^2+a_2^2)^{3/2}}$$

穿过 $C_2$ 的互感磁通链：

$$\Psi_{21} = \oint_{C_2}\vec{A}_1\cdot d\vec{l}_2 = A_1\cdot 2\pi a_2 = \frac{\mu_0 a_1^2 I_1 a_2}{4(d^2+a_2^2)^{3/2}}\cdot 2\pi a_2$$

互感：

$$M = \frac{\Psi_{21}}{I_1} = \frac{\mu_0\pi a_1^2 a_2^2}{2(d^2+a_2^2)^{3/2}}$$

与方法一结果完全一致。

> **方法二的物理图像**：当 $C_1$ 很小（$a_1 \ll d$）时，它在 $C_2$ 处的磁场已经是"磁偶极子"的远场，可以用已知的磁偶极子公式直接求矢量磁位，大大简化计算。
