# 例 3.3.7 同轴线单位长度磁场能量与自感（含厚外导体）

## 题目

同轴线横截面图如图所示：内导体半径为 $a$，外导体内半径为 $b$，外半径为 $c$。内外导体之间填充磁导率为 $\mu_0$ 的介质，导体本身磁导率也为 $\mu_0$。电流为 $I$，求同轴线单位长度内储存的磁场能量与自感。

---

## 解题过程

### 第一步：用安培环路定理求三个区域的磁场

**区域1（$0 \leq \rho \leq a$，内导体内部）**

电流均匀分布，面积为 $\pi a^2$，半径 $\rho$ 内包围的电流为 $I\cdot(\rho^2/a^2)$：

$$\vec{H}_1 = \vec{e}_\phi\frac{I\rho}{2\pi a^2}$$

**区域2（$a \leq \rho \leq b$，绝缘介质层）**

包围的总电流为 $I$：

$$\vec{H}_2 = \vec{e}_\phi\frac{I}{2\pi\rho}$$

**区域3（$b \leq \rho \leq c$，外导体内部）**

外导体通过 $-I$（与内导体反向），均匀分布在面积 $\pi(c^2-b^2)$ 上。在 $\rho$ 处，圆环内包含的返回电流为 $I\cdot\dfrac{\rho^2-b^2}{c^2-b^2}$，故安培环路内净电流：

$$I_{enc} = I - I\cdot\frac{\rho^2-b^2}{c^2-b^2} = I\cdot\frac{c^2-\rho^2}{c^2-b^2}$$

$$\vec{H}_3 = \vec{e}_\phi\frac{I}{2\pi\rho}\cdot\frac{c^2-\rho^2}{c^2-b^2}$$

---

### 第二步：计算各区域单位长度的磁场能量

磁场能量密度为 $w_m = \dfrac{1}{2}\mu_0 H^2$，对单位长度（取 $z$ 方向，长为1），在半径 $\rho$ 的圆柱壳内能量为 $\dfrac{1}{2}\mu_0 H^2\cdot 2\pi\rho\,d\rho$。

**区域1（内导体内部）**：

$$W_{m1} = \frac{\mu_0}{2}\int_0^a \left(\frac{I\rho}{2\pi a^2}\right)^2 2\pi\rho\,d\rho = \frac{\mu_0 I^2}{4\pi a^4}\int_0^a\rho^3\,d\rho = \frac{\mu_0 I^2}{16\pi}$$

**区域2（介质层）**：

$$W_{m2} = \frac{\mu_0}{2}\int_a^b\left(\frac{I}{2\pi\rho}\right)^2 2\pi\rho\,d\rho = \frac{\mu_0 I^2}{4\pi}\int_a^b\frac{d\rho}{\rho} = \frac{\mu_0 I^2}{4\pi}\ln\frac{b}{a}$$

**区域3（外导体内部）**：

$$W_{m3} = \frac{\mu_0}{2}\int_b^c\left(\frac{I}{2\pi\rho}\cdot\frac{c^2-\rho^2}{c^2-b^2}\right)^2 2\pi\rho\,d\rho$$

$$= \frac{\mu_0 I^2}{4\pi(c^2-b^2)^2}\int_b^c\frac{(c^2-\rho^2)^2}{\rho}\,d\rho$$

展开 $(c^2-\rho^2)^2 = c^4 - 2c^2\rho^2 + \rho^4$，分项积分：

$$\int_b^c\frac{c^4-2c^2\rho^2+\rho^4}{\rho}d\rho = c^4\ln\frac{c}{b} - 2c^2\cdot\frac{c^2-b^2}{2} + \frac{c^4-b^4}{4}$$

$$= c^4\ln\frac{c}{b} - c^2(c^2-b^2) + \frac{(c^2-b^2)(c^2+b^2)}{4}$$

$$= c^4\ln\frac{c}{b} - (c^2-b^2)\left[c^2 - \frac{c^2+b^2}{4}\right] = c^4\ln\frac{c}{b} - (c^2-b^2)\cdot\frac{3c^2-b^2}{4}$$

故：

$$W_{m3} = \frac{\mu_0 I^2}{4\pi}\left[\frac{c^4}{(c^2-b^2)^2}\ln\frac{c}{b} - \frac{3c^2-b^2}{4(c^2-b^2)}\right]$$

---

### 第三步：求总磁场能量与自感

$$W_m = W_{m1}+W_{m2}+W_{m3} = \frac{\mu_0 I^2}{4\pi}\left[\frac{1}{4}+\ln\frac{b}{a}+\frac{c^4}{(c^2-b^2)^2}\ln\frac{c}{b}-\frac{3c^2-b^2}{4(c^2-b^2)}\right]$$

由 $W_m = \dfrac{1}{2}LI^2$，单位长度自感：

> $$\boxed{L = \frac{2W_m}{I^2} = \frac{\mu_0}{2\pi}\left[\frac{1}{4}+\ln\frac{b}{a}+\frac{c^4}{(c^2-b^2)^2}\ln\frac{c}{b}-\frac{3c^2-b^2}{4(c^2-b^2)}\right]}$$

---

## 结构说明

与[[例 3.3.3|例3.3.3（理想薄外导体同轴线）]]相比，本题外导体有厚度，多出区域3的贡献 $W_{m3}$（外导体内自感）。当外导体很薄（$c\to b$）时，区域3的贡献趋于零，退化为例3.3.3的结果。
