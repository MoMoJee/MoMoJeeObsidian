# 例 3.3.9 两同轴圆形线圈之间的磁场力

## 题目

两个互相平行且共轴的圆形线圈，距离为 $d$，半径分别为 $a_1$ 和 $a_2$，其中 $a_1 \ll d$。两线圈中分别载有电流 $I_1$ 和 $I_2$，求两线圈间的磁场力。

---

## 解题过程

### 第一步：利用例 3.3.6 的互感结果

由[[例 3.3.6|例3.3.6]]，当 $a_1 \ll d$ 时，两线圈间的互感为：

$$M = \frac{\pi\mu_0 a_1^2 a_2^2}{2(a_2^2+d^2)^{3/2}}$$

### 第二步：用互感计算磁场力

两个载流回路之间的磁场力可由磁场能量对相对位移的偏导数求得。设距离 $d$ 为广义坐标，在恒定电流（$I = \text{常数}$）条件下：

$$F_{21} = I_1 I_2\frac{\partial M}{\partial d}\bigg|_{I = \text{常数}}$$

（此公式表明：若两线圈的互感随距离 $d$ 增大而减小，则力为负，即为吸引力）

### 第三步：对 $d$ 求偏导

$$\frac{\partial M}{\partial d} = \frac{\pi\mu_0 a_1^2 a_2^2}{2}\cdot\frac{\partial}{\partial d}(a_2^2+d^2)^{-3/2} = \frac{\pi\mu_0 a_1^2 a_2^2}{2}\cdot\left(-\frac{3}{2}\right)\cdot 2d\cdot(a_2^2+d^2)^{-5/2}$$

$$= -\frac{3\pi\mu_0 a_1^2 a_2^2 d}{2(a_2^2+d^2)^{5/2}}$$

### 第四步：求磁场力

> $$\boxed{F_{21} = I_1 I_2\frac{\partial M}{\partial d} = -\frac{3\pi I_1 I_2\mu_0 a_1^2 a_2^2 d}{2(a_2^2+d^2)^{5/2}}}$$

---

## 结果说明

**负号的含义**：

$$F_{21} = -\frac{3\pi I_1 I_2\mu_0 a_1^2 a_2^2 d}{2(a_2^2+d^2)^{5/2}}$$

- 当 $I_1$ 与 $I_2$ 方向==相同==时，$I_1 I_2 > 0$，$F_{21} < 0$，即力指向 $d$ 减小方向，两线圈==相互吸引==。
- 当 $I_1$ 与 $I_2$ 方向==相反==时，$I_1 I_2 < 0$，$F_{21} > 0$，即力指向 $d$ 增大方向，两线圈==相互排斥==。

**力随距离的变化**：分母中 $d$ 为 5/2 次方，力随距离增大迅速衰减，体现了磁偶极子远场的特性。
