# 例 3.3.2 无限长直线电流的矢量磁位

## 题目

求沿 $z$ 轴方向流动、电流为 $I$ 的无限长直线电流的矢量磁位 $\vec{A}$ 和磁感应强度 $\vec{B}$。

---

## 解题过程

### 第一步：先求有限长 $2l$ 的直线电流的矢量磁位

取场点 $P(\rho, \phi, z)$（柱坐标），源点在 $z$ 轴上，位置为 $z'$，线元为 $d\vec{l}' = \vec{e}_z\,dz'$，到场点距离为：

$$|\vec{r}-\vec{r}'| = \sqrt{\rho^2 + (z-z')^2}$$

由[[3.3.2_恒定磁场的矢量磁位和标量磁位|线电流矢量磁位积分公式]]，线元 $I\,dz'$ 在场点的贡献：

$$d\vec{A} = \vec{e}_z\frac{\mu_0 I\,dz'}{4\pi\sqrt{\rho^2+(z-z')^2}}$$

对 $z'$ 从 $-l$ 到 $+l$ 积分：

$$\vec{A} = \vec{e}_z\frac{\mu_0 I}{4\pi}\int_{-l}^{l}\frac{dz'}{\sqrt{\rho^2+(z-z')^2}}$$

利用积分公式 $\displaystyle\int\frac{du}{\sqrt{u^2+a^2}} = \ln\!\left[u + \sqrt{u^2+a^2}\right] + C$，令 $u = z - z'$，$a = \rho$，积分结果为：

$$\vec{A} = \vec{e}_z\frac{\mu_0 I}{4\pi}\ln\!\left[\frac{(l-z)+\sqrt{(l-z)^2+\rho^2}}{-(l+z)+\sqrt{(l+z)^2+\rho^2}}\right]$$

---

### 第二步：取极限 $l\to\infty$

当 $l \gg \rho$、$l \gg |z|$ 时，对分子分母分别近似：

- 分子：$(l-z) + \sqrt{(l-z)^2+\rho^2} \approx (l-z) + (l-z)\sqrt{1+\rho^2/(l-z)^2} \approx 2(l-z) \approx 2l$
- 分母：$-(l+z) + \sqrt{(l+z)^2+\rho^2} \approx -(l+z) + (l+z) \approx \rho^2/[2(l+z)] \approx \rho^2/(2l)$

更精确地，利用 $l \gg \rho$ 的近似：

$$\vec{A} \approx \vec{e}_z\frac{\mu_0 I}{4\pi}\ln\!\left[\frac{l+\sqrt{l^2+\rho^2}}{-l+\sqrt{l^2+\rho^2}}\right] \approx \vec{e}_z\frac{\mu_0 I}{4\pi}\ln\!\left(\frac{2l}{\rho}\right)^2 = \vec{e}_z\frac{\mu_0 I}{2\pi}\ln\!\frac{2l}{\rho}$$

---

### 第三步：处理无限大的问题——选取参考零点

$l \to \infty$ 时，$\vec{A} \to \infty$。这是因为无限长直线电流从无穷远处延伸，**无法将无穷远处作为矢量磁位的参考零点**（这与点电荷/有限源的情况不同，无限长源的势在无穷远处本身就发散）。

解决方法：在有限距离 $\rho = \rho_0$ 处人为规定 $\vec{A} = \vec{0}$，即令：

$$\vec{A}\big|_{\rho=\rho_0} = \vec{e}_z\frac{\mu_0 I}{2\pi}\ln\frac{2l}{\rho_0} + \vec{C} = \vec{0}$$

得到积分常数：$\vec{C} = -\vec{e}_z\dfrac{\mu_0 I}{2\pi}\ln\dfrac{2l}{\rho_0}$

> **这样处理是合理的**：在 $\vec{A}$ 的表达式上叠加任意常矢量 $\vec{C}$，不影响磁感应强度 $\vec{B} = \nabla\times\vec{A}$ 的计算（常数的旋度为零）。

加上常数后，矢量磁位为：

$$\vec{A} = \vec{e}_z\frac{\mu_0 I}{2\pi}\ln\frac{2l}{\rho} - \vec{e}_z\frac{\mu_0 I}{2\pi}\ln\frac{2l}{\rho_0}$$

> $$\boxed{\vec{A} = \vec{e}_z\frac{\mu_0 I}{2\pi}\ln\frac{\rho_0}{\rho}}$$

---

### 第四步：由 $\vec{A}$ 求 $\vec{B}$

$\vec{A}$ 只有 $z$ 分量且只与 $\rho$ 有关，在柱坐标中旋度化简为：

$$\vec{B} = \nabla\times\vec{A} = -\vec{e}_\phi\frac{\partial A_z}{\partial\rho}$$

代入 $A_z = \dfrac{\mu_0 I}{2\pi}\ln\dfrac{\rho_0}{\rho} = -\dfrac{\mu_0 I}{2\pi}\ln\rho + \text{const}$：

$$\frac{\partial A_z}{\partial\rho} = -\frac{\mu_0 I}{2\pi\rho}$$

> $$\boxed{\vec{B} = \vec{e}_\phi\frac{\mu_0 I}{2\pi\rho}}$$

这与由安培环路定理直接得到的结果完全一致，验证了矢量磁位方法的正确性。

---

## 关键小结

| 要点 | 说明 |
|------|------|
| 无限长直线的 $\vec{A}$ 发散 | 不能以无穷远为参考点，须在有限处选参考零点 $\rho_0$ |
| 常矢量 $\vec{C}$ 可以自由加 | 不影响 $\vec{B} = \nabla\times\vec{A}$，这是[[3.3.2_恒定磁场的矢量磁位和标量磁位\|规范变换任意性]]的体现 |
| $\vec{B}$ 不依赖 $\rho_0$ 的选取 | 微分运算消去了常数，$\vec{B}$ 是唯一确定的物理量 |
