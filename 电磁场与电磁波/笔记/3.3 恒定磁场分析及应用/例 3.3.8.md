# 例 3.3.8 电磁铁对衔铁的吸引力

## 题目

一个电磁铁由铁轭（绕有 $N$ 匝线圈的铁心）和衔铁构成。铁轭和衔铁的横截面积均为 $S$，平均长度分别为 $l_1$ 和 $l_2$。铁轭与衔铁之间有很小的空气隙，其长度为 $x$。设线圈中的电流为 $I$，铁轭和衔铁的磁导率为 $\mu$，忽略漏磁和边缘效应，求铁轭对衔铁的吸引力。

---

## 方法一：保持磁通 $\Psi$ 不变，用虚位移法（等磁通约束）

### 物理依据

在忽略漏磁和边缘效应的前提下，若磁通 $\Psi$（即 $\vec{B}$ 的通量）不变，则：
- 铁心和衔铁中的磁场 $\vec{B}$、$\vec{H}$ 不变，储存在铁心和衔铁中的能量不变。
- 只有空气隙中的能量发生变化。

磁场力的虚位移公式（等磁通约束）：

$$F_x = -\frac{\partial W_m}{\partial x}\bigg|_{\Psi = \text{常数}}$$

（负号：系统趋向能量减小的方向运动，即减小气隙，拉向铁心）

### 计算空气隙中的能量

两个气隙的总长为 $2x$，磁场能量密度为 $\dfrac{B_0^2}{2\mu_0}$，总体积为 $2xS$，故空气隙能量为：

$$W_{气隙} = 2xS\cdot\frac{B_0^2}{2\mu_0} = \frac{SB_0^2 x}{\mu_0}$$

对 $x$ 求偏导（$\Psi$ 不变即 $B_0$ 不变）：

$$F_x = -\frac{\partial W_{气隙}}{\partial x} = -\frac{SB_0^2}{\mu_0}$$

### 确定 $B_0$

由安培环路定理（沿磁路一周，经铁轭 $l_1$、衔铁 $l_2$、两段气隙 $2x$）：

$$H(l_1+l_2) + 2H_0 x = NI$$

铁中 $H = B/\mu = B_0/\mu$（因 $B = B_0$，连续），气隙中 $H_0 = B_0/\mu_0$，故：

$$\frac{B_0}{\mu}(l_1+l_2) + \frac{2B_0}{\mu_0}x = NI$$

$$B_0\left[\frac{l_1+l_2}{\mu} + \frac{2x}{\mu_0}\right] = NI$$

$$B_0 = \frac{\mu_0\mu NI}{(l_1+l_2)\mu_0 + 2\mu x}$$

### 最终吸引力

> $$\boxed{F_x = -\frac{SB_0^2}{\mu_0} = -\frac{\mu_0\mu^2 N^2 I^2 S}{\left[(l_1+l_2)\mu_0 + 2\mu x\right]^2}}$$

（负号表示力方向为 $x$ 减小的方向，即吸引）

---

## 方法二：保持电流 $I$ 不变，用虚位移法（等电流约束）

### 物理依据

在恒流源条件下，虚位移公式：

$$F_x = +\frac{\partial W_m}{\partial x}\bigg|_{I = \text{常数}}$$

（正号：恒流时，电源做功一半转化为机械能，一半增加磁场能）

### 计算总磁场能量

系统总磁链 $\Psi = NIS B_0/I$，实际上系统等效电感 $L = \Psi/I$，总磁场能量：

$$W_m = \frac{1}{2}NIS B_0 = \frac{1}{2}\cdot N I\cdot S\cdot\frac{\mu_0\mu NI}{(l_1+l_2)\mu_0+2\mu x} = \frac{\mu_0\mu SN^2 I^2}{2\left[(l_1+l_2)\mu_0+2\mu x\right]}$$

### 对 $x$ 求偏导（$I$ 不变）

$$F_x = \frac{\partial W_m}{\partial x}\bigg|_{I} = \frac{\mu_0\mu SN^2 I^2}{2}\cdot\frac{-2\mu}{[(l_1+l_2)\mu_0+2\mu x]^2} = -\frac{\mu_0\mu^2 N^2 I^2 S}{[(l_1+l_2)\mu_0+2\mu x]^2}$$

两种方法结果完全相同，验证了磁场力计算的一致性。

---

## 物理理解

**为什么两种方法结果相同？**
虚位移法的两种约束（等磁通 vs 等电流）虽然中间步骤不同，但最终物理上描述的是同一个力。数学上两种途径是等价的。

**吸引力的方向**：衔铁被铁轭吸引（气隙减小），$F_x$ 为负表示力指向 $x$ 减小的方向。

**电磁铁设计参数**：气隙 $x$ 越小，吸引力越大；$NI$（安匝数）越大，吸引力越大；截面 $S$ 越大，吸引力越大。
