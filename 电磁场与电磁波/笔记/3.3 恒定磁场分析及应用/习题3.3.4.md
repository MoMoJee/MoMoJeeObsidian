# 习题 3.3.4 双缠绕非磁芯螺线管的总磁能

## 题目

如图所示的双缠绕非磁芯（$\mu = \mu_0$）螺线管，次级绕线缠绕在同心主线圈上，参数为：
- $N_1 = 1000$，$N_2 = 100$
- $l_1 = 10\ \text{cm}$，$l_2 = 5\ \text{cm}$，$a = 1\ \text{cm}$
- 流经两个线圈的电流：$I_1 = I_2 = 1\ \text{mA}$

忽略从端部泄漏的磁通，计算存储在该系统中的总磁能。

---

## 解题过程

### 第一步：求各线圈的自感

螺线管的自感公式：$L = \mu_0\dfrac{N^2}{l}\cdot\pi a^2$（单位为 H）

**外线圈（$N_1, l_1$）**：

$$L_1 = \mu_0\frac{N_1^2}{l_1}\cdot\pi a^2 = 4\pi\times10^{-7}\times\frac{1000^2}{0.10}\times\pi\times(0.01)^2$$

$$= 4\pi\times10^{-7}\times10^7\times\pi\times10^{-4} = 4\pi^2\times10^{-4}\ \text{H} \approx 3.948\times10^{-3}\ \text{H}$$

**内线圈（$N_2, l_2$）**：

$$L_2 = \mu_0\frac{N_2^2}{l_2}\cdot\pi a^2 = 4\pi\times10^{-7}\times\frac{100^2}{0.05}\times\pi\times(0.01)^2$$

$$= 4\pi\times10^{-7}\times2\times10^5\times\pi\times10^{-4} = 8\pi^2\times10^{-6}\ \text{H} \approx 7.896\times10^{-5}\ \text{H}$$

---

### 第二步：求两线圈之间的互感

内线圈（$N_2$，长度 $l_2$）完全套在外线圈（$N_1$，长度 $l_1$）内部。

**由 $C_1$ 对 $C_2$ 的互感**：

外线圈 $C_1$ 通电流 $I_1$ 时，在其内部产生均匀磁场（忽略端部效应）：

$$B_1 = \mu_0\frac{N_1}{l_1}I_1$$

穿过内线圈（$N_2$ 匝，面积 $\pi a^2$）的互感磁通链：

$$\Psi_{21} = N_2\cdot B_1\cdot\pi a^2 = N_2\cdot\mu_0\frac{N_1}{l_1}\cdot\pi a^2\cdot I_1$$

互感：

$$M = \frac{\Psi_{21}}{I_1} = \mu_0\frac{N_1 N_2}{l_1}\cdot\pi a^2 = 4\pi\times10^{-7}\times\frac{1000\times100}{0.10}\times\pi\times(0.01)^2$$

$$= 4\pi\times10^{-7}\times10^6\times\pi\times10^{-4} = 4\pi^2\times10^{-5}\ \text{H} \approx 3.948\times10^{-4}\ \text{H}$$

---

### 第三步：计算总磁场能量

双线圈系统的总磁场能量（耦合系统）：

$$W_m = \frac{1}{2}L_1 I_1^2 + MI_1 I_2 + \frac{1}{2}L_2 I_2^2$$

（互感项的符号取决于两线圈绕向：若两线圈产生的磁场方向相同取正号，相反取负号；本题假设同向绕制）

代入数值（$I_1 = I_2 = 1\times10^{-3}\ \text{A}$）：

$$W_m = \frac{1}{2}\times(4\pi^2\times10^{-4})\times(10^{-3})^2 + (4\pi^2\times10^{-5})\times(10^{-3})^2 + \frac{1}{2}\times(8\pi^2\times10^{-6})\times(10^{-3})^2$$

$$= \frac{1}{2}\times4\pi^2\times10^{-10} + 4\pi^2\times10^{-11} + \frac{1}{2}\times8\pi^2\times10^{-12}$$

$$= 2\pi^2\times10^{-10} + 4\pi^2\times10^{-11} + 4\pi^2\times10^{-12}$$

$$= \pi^2\times10^{-10}\left(2 + 0.4 + 0.04\right) = 2.44\pi^2\times10^{-10}\ \text{J}$$

> $$\boxed{W_m = 2.44\pi^2\times10^{-10}\ \text{J} \approx 2.408\times10^{-9}\ \text{J} \approx 2.41\ \text{nJ}}$$

---

## 物理说明

**为什么互感磁通链只考虑 $C_1$ 对 $C_2$ 的单向计算？**

内线圈 $C_2$ 完全套在外线圈 $C_1$ 内，所以 $C_1$ 产生的磁通==全部穿过== $C_2$（忽略端部漏磁）。而 $C_2$ 产生的磁通只有一部分穿过 $C_1$（因为 $C_2$ 较短），但由互感的互易性 $M_{12} = M_{21} = M$，两种计算方式得到相同的 $M$，这里取 $C_1\to C_2$ 方向计算更简便。
