# 例 3.3.5 长直导线与三角形回路之间的互感

## 题目

长直导线沿 $z$ 轴方向，通过电流 $I$。在 $xOz$ 平面内有一个等腰三角形导线回路，底边长度为 $b$，底边右端距直导线的距离为 $d$，顶角为 $60°$（从底边中点向上，即 $z$ 方向）。两者共面，求它们之间的互感 $M$。

---

## 解题过程

### 第一步：求长直导线产生的磁感应强度

由安培环路定理，长直导线在距其 $x$ 处产生的磁场（仅有 $\phi$ 方向，在 $xOz$ 平面内为 $y$ 方向，垂直于纸面向外）：

$$\vec{B} = \vec{e}_\phi\frac{\mu_0 I}{2\pi x}$$

---

### 第二步：建立三角形面积元，确定积分变量

三角形底边位于 $x$ 轴上，从 $x=d$ 到 $x=d+b$，顶角在底边右端（$x=d+b$ 处），顶角为 $60°$。

在 $x$ 处取一宽度为 $dx$ 的竖直条形面积元，高度 $z$ 为：

三角形的斜边从底边右端 $(x=d+b, z=0)$ 向左延伸，斜率为 $\tan 60° = \sqrt{3}$，所以高度为：

$$z = (b+d - x)\tan 60° = \sqrt{3}\,(b+d-x)$$

这个面积元的面积为 $dS = z\,dx = \sqrt{3}(b+d-x)\,dx$，$\vec{B}$ 垂直穿过此面积元（$\vec{B}$ 方向与平面法线方向一致）。

---

### 第三步：计算穿过三角形的总磁通链

$$\Psi = \int_S \vec{B}\cdot d\vec{S} = \frac{\mu_0 I}{2\pi}\int_d^{d+b}\frac{1}{x}\cdot\sqrt{3}(b+d-x)\,dx$$

$$= \frac{\sqrt{3}\,\mu_0 I}{2\pi}\int_d^{d+b}\frac{b+d-x}{x}\,dx$$

整理被积函数：$\dfrac{b+d-x}{x} = \dfrac{b+d}{x} - 1$，故：

$$\Psi = \frac{\sqrt{3}\,\mu_0 I}{2\pi}\int_d^{d+b}\left(\frac{b+d}{x} - 1\right)dx$$

$$= \frac{\sqrt{3}\,\mu_0 I}{2\pi}\left[(b+d)\ln x - x\right]_d^{d+b}$$

$$= \frac{\sqrt{3}\,\mu_0 I}{2\pi}\left[(b+d)\ln\frac{d+b}{d} - b\right]$$

$$= \frac{\sqrt{3}\,\mu_0 I}{2\pi}\left[(b+d)\ln\!\left(1+\frac{b}{d}\right) - b\right]$$

---

### 第四步：求互感

由[[3.3.3_电感|互感定义]] $M = \Psi_{21}/I_1$：

> $$\boxed{M = \frac{\Psi}{I} = \frac{\sqrt{3}\,\mu_0}{2\pi}\left[(b+d)\ln\!\left(1+\frac{b}{d}\right) - b\right]}$$

---

## 关键步骤说明

**为什么面积元高度用 $z = \sqrt{3}(b+d-x)$？**

三角形顶点在底边右端（$x = d+b$），顶角为 $60°$，斜边从右端出发向左上方倾斜。在水平位置 $x$ 处（$d \leq x \leq d+b$），三角形的高度等于从 $x$ 到右端的水平距离 $(d+b-x)$ 乘以斜率 $\tan 60° = \sqrt{3}$。

**互感的符号**：此处计算的是磁通链与电流之比，结果为正，说明两回路互感为正——当长直导线电流增加时，穿过三角形回路的磁通增加，感应电动势方向由楞次定律决定。
