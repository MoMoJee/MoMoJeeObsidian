# 例 3.3.1 小圆环电流的矢量磁位与磁场（磁偶极子）

## 题目

半径为 $a$ 的小圆环位于 $xy$ 平面内，圆心在原点，通过电流 $I$。求圆环电流的矢量磁位 $\vec{A}$ 和磁感应强度 $\vec{B}$（远场近似，$r \gg a$）。

---

## 建立坐标与几何关系

由于场具有关于 $z$ 轴的旋转对称性，取 $xz$ 平面内的一点 $P(r,\theta,0)$ 作为场点，不失一般性。用球坐标表示该点：

$$\vec{r} = \vec{e}_x r\sin\theta + \vec{e}_z r\cos\theta$$

圆环上的源点用参数 $\phi'$（$0 \sim 2\pi$）描述：

$$\vec{r}' = \vec{e}_x a\cos\phi' + \vec{e}_y a\sin\phi'$$

圆环上的电流线元（对 $\phi'$ 求微分，乘以 $a$）：

$$d\vec{l}' = \vec{e}_{\phi'} a\,d\phi' = (-\vec{e}_x\sin\phi' + \vec{e}_y\cos\phi')a\,d\phi'$$

---

## 计算场点到源点的距离

$$|\vec{r}-\vec{r}'|^2 = (r\sin\theta - a\cos\phi')^2 + (a\sin\phi')^2 + (r\cos\theta)^2$$

展开整理：

$$= r^2 + a^2 - 2ar\sin\theta\cos\phi'$$

$$\therefore \quad |\vec{r}-\vec{r}'| = \sqrt{r^2 + a^2 - 2ar\sin\theta\cos\phi'}$$

---

## 远场近似（$r \gg a$）

提取 $r$，将根号内视为 $1 + \varepsilon$（$\varepsilon \ll 1$）型展开：

$$\frac{1}{|\vec{r}-\vec{r}'|} = \frac{1}{r}\left[1 + \left(\frac{a}{r}\right)^2 - \frac{2a}{r}\sin\theta\cos\phi'\right]^{-1/2}$$

忽略 $(a/r)^2$ 项（二阶小量），利用 $(1+\varepsilon)^{-1/2} \approx 1 - \varepsilon/2$：

$$\approx \frac{1}{r}\left(1 - \frac{2a}{r}\sin\theta\cos\phi'\right)^{-1/2} \approx \frac{1}{r}\left(1 + \frac{a}{r}\sin\theta\cos\phi'\right)$$

---

## 代入矢量磁位积分公式

[[3.3.2_恒定磁场的矢量磁位和标量磁位（标量刺猬期末不考但是考研考）|线电流矢量磁位的积分公式]]：

$$\vec{A}(\vec{r}) = \frac{\mu_0 I}{4\pi}\oint_C \frac{d\vec{l}'}{|\vec{r}-\vec{r}'|}$$

代入上面的近似展开：

$$\vec{A} = \frac{\mu_0 I a}{4\pi}\int_0^{2\pi} \frac{1}{r}\left(1 + \frac{a}{r}\sin\theta\cos\phi'\right)(-\vec{e}_x\sin\phi' + \vec{e}_y\cos\phi')\,d\phi'$$

**逐项积分**（利用 $\int_0^{2\pi}\sin\phi'\,d\phi' = 0$，$\int_0^{2\pi}\cos\phi'\,d\phi' = 0$，$\int_0^{2\pi}\cos^2\phi'\,d\phi' = \pi$，$\int_0^{2\pi}\sin\phi'\cos\phi'\,d\phi' = 0$）：

- $\int_0^{2\pi}(-\vec{e}_x\sin\phi' + \vec{e}_y\cos\phi')\,d\phi' = \vec{0}$（常数项积分为零）
- $\int_0^{2\pi}\cos\phi'(-\vec{e}_x\sin\phi' + \vec{e}_y\cos\phi')\,d\phi' = \vec{e}_y\pi$（交叉项 $\sin\phi'\cos\phi'$ 的积分为零，$\cos^2\phi'$ 积分为 $\pi$）

因此：

$$\vec{A} = \frac{\mu_0 Ia}{4\pi}\cdot\frac{1}{r}\cdot\frac{a}{r}\sin\theta\cdot\vec{e}_y\pi = \vec{e}_y\frac{\mu_0\pi a^2 I}{4\pi r^2}\sin\theta$$

**坐标转换**：场点取在 $\phi=0$ 的 $xz$ 平面内，在该平面上 $\vec{e}_y = \vec{e}_\phi$，故：

$$\vec{A} = \vec{e}_\phi\frac{\mu_0 I\pi a^2}{4\pi r^2}\sin\theta = \vec{e}_\phi\frac{\mu_0 IS}{4\pi r^2}\sin\theta$$

其中 $S = \pi a^2$ 是圆环面积。由对称性，该结果对所有 $\phi$ 值均成立。

> $$\boxed{\vec{A}(\vec{r}) = \vec{e}_\phi\frac{\mu_0 IS}{4\pi r^2}\sin\theta}$$

---

## 由矢量磁位求磁感应强度

$\vec{B} = \nabla\times\vec{A}$，在球坐标中，$\vec{A}$ 只有 $\phi$ 分量 $A_\phi$，旋度公式简化为：

$$\vec{B} = \vec{e}_r\frac{1}{r\sin\theta}\frac{\partial}{\partial\theta}(\sin\theta\cdot A_\phi) - \vec{e}_\theta\frac{1}{r}\frac{\partial}{\partial r}(r\cdot A_\phi)$$

代入 $A_\phi = \dfrac{\mu_0 IS}{4\pi r^2}\sin\theta$：

**$\vec{e}_r$ 分量**：

$$\frac{1}{r\sin\theta}\frac{\partial}{\partial\theta}\!\left(\sin\theta\cdot\frac{\mu_0 IS}{4\pi r^2}\sin\theta\right) = \frac{\mu_0 IS}{4\pi r^3\sin\theta}\cdot 2\sin\theta\cos\theta = \frac{\mu_0 IS}{4\pi r^3}\cdot 2\cos\theta$$

**$\vec{e}_\theta$ 分量**（负号）：

$$-\frac{1}{r}\frac{\partial}{\partial r}\!\left(r\cdot\frac{\mu_0 IS}{4\pi r^2}\sin\theta\right) = -\frac{1}{r}\frac{\partial}{\partial r}\!\left(\frac{\mu_0 IS}{4\pi r}\sin\theta\right) = \frac{\mu_0 IS}{4\pi r^3}\sin\theta$$

因此：

> $$\boxed{\vec{B} = \frac{\mu_0 IS}{4\pi r^3}(\vec{e}_r\,2\cos\theta + \vec{e}_\theta\sin\theta)}$$

---

## 磁偶极子的概念

小圆环电流的远场磁场分布与[[3.1.2_电位函数的分析与求解|电偶极子的远场电场分布]]形式完全对应：

| 物理量 | 电偶极子 | 磁偶极子（小圆环） |
|--------|---------|-----------------|
| 偶极矩 | $p = ql$ | $p_m = IS$ |
| 远场势 | $\varphi = \dfrac{p\cos\theta}{4\pi\varepsilon_0 r^2}$ | $A_\phi = \dfrac{\mu_0 p_m\sin\theta}{4\pi r^2}$ |
| 远场 | $\vec{E}\propto\dfrac{1}{r^3}(2\cos\theta\,\vec{e}_r + \sin\theta\,\vec{e}_\theta)$ | $\vec{B}\propto\dfrac{1}{r^3}(2\cos\theta\,\vec{e}_r + \sin\theta\,\vec{e}_\theta)$ |

==磁偶极矩== $p_m = IS$，方向由右手定则确定（与电流回路面积矢量同向）。矢量磁位还可以写成：

$$\vec{A}(\vec{r}) = \frac{\mu_0}{4\pi r^3}\vec{p}_m\times\vec{r}$$
