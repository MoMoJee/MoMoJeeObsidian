# 习题 3.3.5 无限长直导线与矩形回路之间的作用力

## 题目

设一无限长直导线与一矩形回路共面，如图题 3.3.5 所示，其中电流单位为 $A$，$D$、$b$、$a$ 单位均为 $m$。

几何参数：
- 无限长直导线通电流 $I_1$
- 矩形回路边长为 $a$（水平）× $b$（垂直），通电流 $I_2$
- 矩形回路近边距直导线的距离为 $D$

试用虚位移法计算直导线和矩形回路之间的作用力。

---

## 解题过程

### 第一步：计算两者之间的互感 $M$

设矩形回路近边距直导线距离为 $D$（变量），用与[[例 3.3.5|例3.3.5]]类似的方法求穿过矩形回路的磁通。

直导线在距离 $\rho$ 处产生的磁感应强度：（背诵）

$$B_1(\rho) = \frac{\mu_0 I_1}{2\pi\rho}$$

穿过矩形回路（从 $\rho = D$ 到 $\rho = D+b$，长度 $a$）的磁通：

$$\Psi_{21} = \int_D^{D+b}\frac{\mu_0 I_1}{2\pi\rho}\cdot a\,d\rho = \frac{\mu_0 I_1 a}{2\pi}\ln\frac{D+b}{D}$$

互感：

$$M(D) = \frac{\Psi_{21}}{I_1} = \frac{\mu_0 a}{2\pi}\ln\frac{D+b}{D} = \frac{\mu_0 a}{2\pi}\ln\!\left(1+\frac{b}{D}\right)$$

---

### 第二步：用虚位移法（恒电流约束）求力

在恒电流条件下，力为磁场能量对广义坐标 $D$ 的偏导数。对于由互感耦合的两回路，相互作用力为：

$$F = I_1 I_2\frac{\partial M}{\partial D}\bigg|_{I=\text{常数}}$$

对 $M$ 关于 $D$ 求导：

$$\frac{\partial M}{\partial D} = \frac{\mu_0 a}{2\pi}\cdot\frac{\partial}{\partial D}\ln\!\left(1+\frac{b}{D}\right) = \frac{\mu_0 a}{2\pi}\cdot\frac{1}{1+b/D}\cdot\left(-\frac{b}{D^2}\right)$$

$$= \frac{\mu_0 a}{2\pi}\cdot\frac{-b}{D(D+b)} = -\frac{\mu_0 ab}{2\pi D(D+b)}$$

---

### 第三步：最终结果

> $$\boxed{F = I_1 I_2\frac{\partial M}{\partial D} = -\frac{\mu_0 ab I_1 I_2}{2\pi D(D+b)}}$$

---

## 结果分析

**负号的含义**：$F < 0$ 表示力指向 $D$ 减小的方向（矩形回路靠近直导线）。

- 当 $I_1$ 与 $I_2$ 同向时，$I_1 I_2 > 0$，$F < 0$，两回路==相互吸引==。
- 当 $I_1$ 与 $I_2$ 反向时，$I_1 I_2 < 0$，$F > 0$，两回路==相互排斥==。

这与安培定律的直观结论一致：同向电流相吸，反向电流相斥。
