# 本章习题 11 环形螺线管的自感（含气 隙）

## 题目

有一个环形螺线管，环的平均半径为 $R = 15\ \text{cm}$，管的圆形截面半径为 $r_0 = 2\ \text{cm}$，通过电流 $I = 0.7\ \text{A}$，铁芯 $\mu_r = 1400$，环上共绕 $N = 1000$ 匝线圈。

(1) 计算螺线管的自感；
(2) 在铁芯上开一个 $t = 0.1\ \text{cm}$ 的气隙，再计算电感（假设开口后铁芯 $\mu$ 不变）。

---

## 解题过程

### 第一步：计算环形截面积

$$S = \pi r_0^2 = \pi\times(0.02)^2 = 4\pi\times10^{-4}\ \text{m}^2$$

---

## (1) 无气隙时的自感

#### 安培环路定理

取沿铁芯中心线的环形路径（周长 $l = 2\pi R$），由安培环路定理：

$$H\cdot 2\pi R = NI$$

$$H = \frac{NI}{2\pi R} = \frac{1000\times0.7}{2\pi\times0.15} = \frac{700}{0.3\pi} \approx \frac{2333}{1}\ \text{A/m}$$

更简洁的形式：$H = \dfrac{NI}{2\pi R}$

#### 磁感应强度

$$B = \mu_r\mu_0 H = 1400\times4\pi\times10^{-7}\times\frac{NI}{2\pi R} = \frac{\mu_r\mu_0 NI}{2\pi R}$$

#### 总磁通链与自感

穿过 $N$ 匝的总磁通链 $\Psi = N\cdot B\cdot S$，自感：

$$L = \frac{\Psi}{I} = \frac{N\cdot B\cdot S}{I} = \frac{N\cdot\mu_r\mu_0\cdot S}{2\pi R}\cdot N = \frac{\mu_r\mu_0 N^2 S}{2\pi R}$$

代入数值：

$$L = \frac{1400\times4\pi\times10^{-7}\times1000^2\times4\pi\times10^{-4}}{2\pi\times0.15}$$

$$= \frac{1400\times4\pi\times10^{-7}\times10^6\times4\pi\times10^{-4}}{0.3\pi}$$

$$= \frac{1400\times4\times4\times\pi\times10^{-5}}{0.3}$$

$$= \frac{1400\times16\pi\times10^{-5}}{0.3} = \frac{22400\pi\times10^{-5}}{0.3} \approx \frac{22400\times3.1416\times10^{-5}}{0.3}$$

$$\approx \frac{703.7\times10^{-3}}{0.3} \approx 2.346\ \text{H}$$

更规范的计算：

$$L_1 = \frac{\mu_r\mu_0 N^2 S}{l} = \frac{1400\times4\pi\times10^{-7}\times10^6\times4\pi\times10^{-4}}{2\pi\times0.15}$$

$$= \frac{1400\times4\pi\times10^{-7}\times4\pi\times10^{2}}{2\pi\times0.15} = \frac{1400\times4\pi\times4\pi\times10^{-5}}{2\pi\times0.15}$$

$$= \frac{1400\times8\pi\times10^{-5}}{0.15} = \frac{11200\pi\times10^{-5}}{0.15} \approx 2.346\ \text{H}$$

> $$\boxed{L_1 = \frac{\mu_r\mu_0 N^2 S}{2\pi R} \approx 2.35\ \text{H}}$$

---

## (2) 开气隙后的电感

#### 安培环路定理（含气隙）

铁芯磁路长度变为 $l_{Fe} = 2\pi R - t$，气隙长度为 $t$。安培环路：

$$H_{Fe}(2\pi R - t) + H_g\cdot t = NI$$

由 $B$ 的法向分量在界面连续：$B_{Fe} = B_g = B$，故：

$$H_{Fe} = \frac{B}{\mu_r\mu_0}, \quad H_g = \frac{B}{\mu_0}$$

代入：

$$\frac{B}{\mu_r\mu_0}(2\pi R - t) + \frac{B}{\mu_0}\cdot t = NI$$

$$B\left[\frac{2\pi R - t}{\mu_r\mu_0} + \frac{t}{\mu_0}\right] = NI$$

$$B = \frac{\mu_r\mu_0 NI}{(2\pi R - t) + \mu_r t}$$

#### 自感计算

$$L_2 = \frac{N\cdot B\cdot S}{I} = \frac{\mu_r\mu_0 N^2 S}{(2\pi R - t) + \mu_r t}$$

代入数值（$t = 0.001\ \text{m}$，$2\pi R = 2\pi\times0.15 \approx 0.9425\ \text{m}$）：

分母 $= (0.9425 - 0.001) + 1400\times0.001 = 0.9415 + 1.4 = 2.3415\ \text{m}$

$$L_2 = \frac{1400\times4\pi\times10^{-7}\times10^6\times4\pi\times10^{-4}}{2.3415}$$

分子与之前相同：$= 1400\times4\pi\times4\pi\times10^{-5} = 1400\times16\pi^2\times10^{-5}$

$= 1400\times16\times9.8696\times10^{-5} = 1400\times1.5791\times10^{-3} = 2.2108\times10^{0}$

$$L_2 = \frac{2.2108}{2.3415} \approx 0.944\ \text{H}$$

> $$\boxed{L_2 = \frac{\mu_r\mu_0 N^2 S}{(2\pi R - t) + \mu_r t} \approx 0.94\ \text{H}}$$

---

## 对比与物理解释

| | 无气隙 | 有气隙（$t = 1\ \text{mm}$）|
|---|---|---|
| 自感 | $\approx 2.35\ \text{H}$ | $\approx 0.94\ \text{H}$ |

气隙虽然只有 $1\ \text{mm}$，但由于 $\mu_r = 1400$，相当于把磁阻增加了约 $\mu_r\cdot t/(l) = 1400\times1/942.5 \approx 1.49$ 倍（相对于总磁路长度），导致自感减少到原来的约 $2\pi R / [(2\pi R - t) + \mu_r t] \approx 0.942/2.342 \approx 0.40$ 倍。

这就是铁芯气隙在变压器和电感元件设计中被用来==精确控制电感量==的原理。
