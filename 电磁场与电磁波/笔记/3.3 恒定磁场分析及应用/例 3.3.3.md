# 例 3.3.3 同轴线单位长度的自感（内自感 + 外自感）

## 题目

同轴线内导体半径为 $a$，外导体内半径为 $b$（外导体厚度忽略不计）。内外导体材料为铜（磁导率 $\mu_0$），介质也为 $\mu_0$。计算同轴线单位长度的自感。

---

## 基本思路

自感 $L = \Psi / I$，需要计算通过回路截面的磁通链 $\Psi$。同轴线的磁场分布分为两个区域：
- **内导体内部**（$0 < \rho < a$）：电流均匀分布在截面上，产生内自感；
- **内外导体之间**（$a < \rho < b$）：同轴安培结构，产生外自感。

---

## 一、内导体内部的内自感 $L_i$

### 第一步：求内导体内部的磁感应强度

设总电流 $I$ 在内导体截面均匀分布，电流密度 $J = I/(\pi a^2)$。对半径 $\rho$（$0<\rho<a$）的安培回路应用安培环路定理：

$$\oint\vec{B}\cdot d\vec{l} = \mu_0 I_{enc} \quad \Rightarrow \quad B\cdot 2\pi\rho = \mu_0 \cdot \frac{\pi\rho^2}{\pi a^2}I$$

$$\vec{B}_i = \vec{e}_\phi\frac{\mu_0 I\rho}{2\pi a^2} \quad (0 < \rho < a)$$

### 第二步：计算磁通量微元

取一个单位长度（$z$ 方向）、宽度为 $d\rho$ 的径向矩形面积元，面积 $dS = 1\cdot d\rho$，其上的磁通量为：

$$d\Phi_i = B_i\,d\rho = \frac{\mu_0 I\rho}{2\pi a^2}\,d\rho$$

### 第三步：关键——"部分磁通"与磁链的折算

这一步是内自感计算的核心，也是最容易出错的地方。

**普通磁通链的定义**：磁链 $\Psi = N\Phi$，即穿过 $N$ 匝的磁通链。但在实心导体内部，情况不同：

穿过半径 $\rho$ 处面积元 $dS$ 的磁通 $d\Phi_i$，只与导体内 $0 \sim \rho$ 圆柱内的那部分电流 $I' = (\rho/a)^2 I$ 相交链，而不是与全部电流 $I$ 交链。

在能量/感应电动势的意义上，只有那部分与磁通交链的电流 $I'$ 才"贡献"了这块磁通对应的自感。因此磁链的贡献需要用**权重** $I'/I$ 来折算：

$$d\Psi_i = \frac{I'}{I}\,d\Phi_i = \left(\frac{\rho}{a}\right)^2\cdot\frac{\mu_0 I\rho}{2\pi a^2}\,d\rho = \frac{\mu_0 I\rho^3}{2\pi a^4}\,d\rho$$

### 第四步：对整个内导体截面积分

$$\Psi_i = \int_0^a\frac{\mu_0 I\rho^3}{2\pi a^4}\,d\rho = \frac{\mu_0 I}{2\pi a^4}\cdot\frac{a^4}{4} = \frac{\mu_0 I}{8\pi}$$

单位长度内自感：

> $$\boxed{L_i = \frac{\Psi_i}{I} = \frac{\mu_0}{8\pi} \quad \text{H/m}}$$

注意：内自感的结果只与磁导率 $\mu_0$ 有关，与导体半径 $a$ 无关！这是因为 $B\propto\rho$ 而面积 $\propto\rho$，两者叠加后的磁链恰好与 $a$ 无关。

---

## 二、内外导体之间的外自感 $L_o$

### 第一步：求介质区域的磁感应强度

在 $a < \rho < b$ 区域内，对安培回路应用安培环路定理（包围全部内导体电流 $I$）：

$$\vec{B}_o = \vec{e}_\phi\frac{\mu_0 I}{2\pi\rho} \quad (a < \rho < b)$$

### 第二步：计算磁通链

此区域的磁通全部与电流 $I$ 交链（内导体和外导体构成闭合回路，磁通穿过两者之间的截面），权重因子为 $1$：

$$d\Psi_o = d\Phi_o = B_o\,d\rho = \frac{\mu_0 I}{2\pi\rho}\,d\rho$$

$$\Psi_o = \int_a^b\frac{\mu_0 I}{2\pi\rho}\,d\rho = \frac{\mu_0 I}{2\pi}\ln\frac{b}{a}$$

单位长度外自感：

> $$\boxed{L_o = \frac{\Psi_o}{I} = \frac{\mu_0}{2\pi}\ln\frac{b}{a} \quad \text{H/m}}$$

---

## 三、同轴线单位长度总自感

$$L = L_i + L_o$$

> $$\boxed{L = \frac{\mu_0}{8\pi} + \frac{\mu_0}{2\pi}\ln\frac{b}{a} \quad \text{H/m}}$$

在高频情况下，由于趋肤效应，电流集中在内导体表面，内导体内部 $B\approx 0$，内自感 $L_i \to 0$，总自感退化为 $L \approx L_o = \dfrac{\mu_0}{2\pi}\ln\dfrac{b}{a}$，与[[3.3.3_电感|3.3.3节笔记]]中的结果完全一致。
