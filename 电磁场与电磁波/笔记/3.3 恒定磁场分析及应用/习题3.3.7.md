# 习题 3.3.7 双层介质同轴圆筒的磁场能量与自感

## 题目

同轴圆筒的内、外导体分别是半径为 $a$ 和 $b$ 的薄圆柱面，厚度可忽略不计。内、外导体间填充有磁导率分别为 $\mu_1$ 和 $\mu_2$ 的两种磁介质，如图所示——介质 $\mu_1$ 占据下半部分（$-\pi < \phi < 0$），介质 $\mu_2$ 占据上半部分（$0 < \phi < \pi$）。设内、外导体圆柱面中的电流为 $I$。

求：(1) 同轴圆筒中单位长度所储存的磁场能量；(2) 同轴圆筒单位长度的自感。

---

## 解题过程

### 第一步：分析磁场分布

本题的特殊之处在于：两种介质沿角度方向（$\phi$ 方向）分布，而不是沿半径方向分层。

在任何一个固定半径 $\rho$（$a < \rho < b$）处取安培环路，由安培环路定理：

$$\oint \vec{H}\cdot d\vec{l} = I_{enc} = I$$

两种介质区域的 $H$ 值：**必须相同**，因为无论从哪条路径（纯 $\mu_1$ 路径或纯 $\mu_2$ 路径）绕一整圈，包围的总电流都是 $I$。但这里实际上两种介质的边界是从内导体到外导体的径向截面。

更准确的分析：取包含两种介质的完整圆形安培环路（半径为 $\rho$），则：

$$H_1\cdot\pi\rho + H_2\cdot\pi\rho = I$$

由于两种介质区域对称（各占半圆），且在界面上 $\vec{B}$ 的切向分量连续（即 $\mu_1 H_1 = \mu_2 H_2$，因为 $B_\phi$ 连续）。

设 $H_1$ 和 $H_2$ 分别为两区域的磁场强度（均沿 $\phi$ 方向）。

由 $B_\phi$ 在两区域界面（$\phi = 0$ 和 $\phi = \pi$ 的径向面）连续：$\mu_1 H_1 = \mu_2 H_2$，即 $H_2 = \dfrac{\mu_1}{\mu_2}H_1$。

代入安培定理：

$$H_1\cdot\pi\rho + \frac{\mu_1}{\mu_2}H_1\cdot\pi\rho = I$$

$$H_1\pi\rho\left(1 + \frac{\mu_1}{\mu_2}\right) = I$$

$$H_1 = \frac{\mu_2 I}{\pi\rho(\mu_1+\mu_2)}, \quad H_2 = \frac{\mu_1 I}{\pi\rho(\mu_1+\mu_2)}$$

磁感应强度：

$$B_1 = \mu_1 H_1 = \frac{\mu_1\mu_2 I}{\pi\rho(\mu_1+\mu_2)}, \quad B_2 = \mu_2 H_2 = \frac{\mu_1\mu_2 I}{\pi\rho(\mu_1+\mu_2)}$$

注意 $B_1 = B_2$，这说明两区域的 $B_\phi$ 相等，满足分界面上 $B$ 切向分量连续的边界条件。

$$B = \frac{\mu_1\mu_2 I}{\pi\rho(\mu_1+\mu_2)} \equiv \frac{2\mu_{eq} I}{2\pi\rho}, \quad \text{其中等效磁导率 }\mu_{eq} = \frac{2\mu_1\mu_2}{\mu_1+\mu_2}$$

（即两种介质并联的调和平均磁导率）

---

### 第二步：计算单位长度磁场能量

分两区域分别积分（各占半圆，即半个环形截面）：

$$W_m = \frac{1}{2}\int_a^b\left(\mu_1 H_1^2\cdot\frac{1}{2}\cdot 2\pi\rho + \mu_2 H_2^2\cdot\frac{1}{2}\cdot 2\pi\rho\right)d\rho$$

（每个区域的体积元为 $\pi\rho\,d\rho$，即半环的面积乘以单位长度）

$$W_m = \int_a^b\left[\frac{\mu_1}{2}\cdot\left(\frac{\mu_2 I}{\pi\rho(\mu_1+\mu_2)}\right)^2\cdot\pi\rho + \frac{\mu_2}{2}\cdot\left(\frac{\mu_1 I}{\pi\rho(\mu_1+\mu_2)}\right)^2\cdot\pi\rho\right]d\rho$$

$$= \frac{\mu_1\mu_2^2 I^2 + \mu_2\mu_1^2 I^2}{2\pi(\mu_1+\mu_2)^2}\int_a^b\frac{d\rho}{\rho} = \frac{\mu_1\mu_2(\mu_1+\mu_2)I^2}{2\pi(\mu_1+\mu_2)^2}\ln\frac{b}{a}$$

$$= \frac{\mu_1\mu_2 I^2}{2\pi(\mu_1+\mu_2)}\ln\frac{b}{a}$$

> $$\boxed{W_m = \frac{\mu_1\mu_2 I^2}{2\pi(\mu_1+\mu_2)}\ln\frac{b}{a}}$$

---

### 第三步：计算自感

由 $W_m = \dfrac{1}{2}LI^2$：

> $$\boxed{L = \frac{2W_m}{I^2} = \frac{\mu_1\mu_2}{\pi(\mu_1+\mu_2)}\ln\frac{b}{a}}$$

---

## 结果验证与特殊情况

当 $\mu_1 = \mu_2 = \mu$ 时，$\dfrac{\mu_1\mu_2}{\pi(\mu_1+\mu_2)} = \dfrac{\mu^2}{\pi\cdot 2\mu} = \dfrac{\mu}{2\pi}$，得 $L = \dfrac{\mu}{2\pi}\ln\dfrac{b}{a}$，与[[例 3.3.3|均匀介质同轴线]]结果一致。
