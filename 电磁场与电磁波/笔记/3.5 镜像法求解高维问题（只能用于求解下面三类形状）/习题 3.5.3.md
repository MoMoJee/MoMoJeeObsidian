# 习题 3.5.3 带电导体球与外部点电荷的静电力

## 题目

半径为 $R$ 的导体球带有电荷 $Q$，在球体外距球心为 $D$ 处有一点电荷 $q$。

1. 求点电荷 $q$ 与导体球之间的静电力；
2. 证明：当 $q$ 与 $Q$ 同号，且 $\dfrac{Q}{q} < \dfrac{RD^3}{(D^2-R^2)^2} - \dfrac{R}{D}$ 时，$F$ 表现为吸引力。

---

## 基本思路

本题是**非接地导体球**的镜像问题。球上有固定总电荷 $Q$（而非接地到 $\varphi=0$）。

处理方法：在[[3.5.2_导体球面的镜像|接地导体球的镜像法]]基础上，分两步叠加：

**第一步**：把球当作接地球，引入镜像电荷 $q_1$（满足球面等位），此时球面上会感应出电荷 $q_1$（不等于 $Q$）；

**第二步**：在球心处再放一个补偿电荷 $q_2$，使球上总电荷变回 $Q$。这个 $q_2$ 放在球心处，不会破坏球面的等位条件（球心到球面各点等距，球心电荷在球面产生均匀电位，仍是等位面）。

---

## 第一步：接地球的镜像电荷

由[[3.5.2_导体球面的镜像|导体球镜像法结论]]（式 3.5.6），设球心在原点，$q$ 在球外距球心 $D$ 处，接地球的镜像电荷为：

$$q_1 = -\frac{R}{D}\,q, \quad d_1 = \frac{R^2}{D} \quad \text{（在球心与 }q\text{ 连线上，距球心 }d_1\text{）}$$

接地球面感应电荷总量为 $q_1$（这是镜像法所给的值）。

---

## 第二步：补偿电荷

球实际总电荷为 $Q$，已有镜像电荷 $q_1 = -Rq/D$，还缺 $Q - q_1 = Q + Rq/D$。

在球心处放置补偿电荷：

$$q_2 = Q - q_1 = Q + \frac{R}{D}\,q$$

球心处的电荷在整个球面产生均匀电位增量，不影响等位条件，因此球面仍为等位面，镜像解仍然合法。

---

## (1) 求点电荷 $q$ 受到的静电力

$q$ 受到 $q_1$ 和 $q_2$ 的库仑力（约定正值为斥力，即沿 $q$ 指向球外方向）：

**$q$ 与 $q_1$ 之间的力**：$q_1$ 在球内距球心 $d_1 = R^2/D$ 处，$q$ 在距球心 $D$ 处，两者相距：

$$D - d_1 = D - \frac{R^2}{D} = \frac{D^2 - R^2}{D}$$

$q$ 受 $q_1$ 的力（$q_1$ 为负值，故为引力，方向朝球）：

$$F_1 = \frac{1}{4\pi\varepsilon_0}\frac{q\cdot q_1}{\left(\dfrac{D^2-R^2}{D}\right)^2} = \frac{1}{4\pi\varepsilon_0}\frac{q\cdot\left(-\dfrac{Rq}{D}\right)}{\dfrac{(D^2-R^2)^2}{D^2}} = -\frac{1}{4\pi\varepsilon_0}\frac{Rq^2 D}{(D^2-R^2)^2}$$

（负号表示方向朝球，即引力）

**$q$ 与 $q_2$ 之间的力**：$q_2$ 在球心，$q$ 距球心 $D$：

$$F_2 = \frac{1}{4\pi\varepsilon_0}\frac{q\cdot q_2}{D^2} = \frac{1}{4\pi\varepsilon_0}\frac{q\left(Q+\dfrac{Rq}{D}\right)}{D^2} = \frac{1}{4\pi\varepsilon_0}\left(\frac{qQ}{D^2}+\frac{Rq^2}{D^3}\right)$$

**总力**（正值为斥力）：

$$F = F_1 + F_2 = \frac{1}{4\pi\varepsilon_0}\left[\frac{qQ}{D^2}+\frac{Rq^2}{D^3} - \frac{Rq^2 D}{(D^2-R^2)^2}\right]$$

> $$\boxed{F = \frac{q}{4\pi\varepsilon_0}\left[\frac{Q}{D^2}+\frac{Rq}{D^3} - \frac{RqD}{(D^2-R^2)^2}\right]}$$

- $F > 0$ 表示斥力（$q$ 被推离球）；
- $F < 0$ 表示引力（$q$ 被球吸引）。

---

## (2) 证明：同号且 $Q/q < RD^3/(D^2-R^2)^2 - R/D$ 时为引力

力 $F < 0$（引力）的条件：

$$\frac{qQ}{D^2}+\frac{Rq^2}{D^3} - \frac{Rq^2 D}{(D^2-R^2)^2} < 0$$

因为 $q$ 与 $Q$ 同号，且假设 $q > 0$（$Q > 0$），则 $q > 0$，不等号方向不变，两边除以 $q$：

$$\frac{Q}{D^2}+\frac{Rq}{D^3} < \frac{RqD}{(D^2-R^2)^2}$$

两边除以 $q$（$q>0$，不变向），再乘以 $D^2$：

$$\frac{Q}{q} + \frac{R}{D} < \frac{RD^3}{(D^2-R^2)^2}$$

即：

$$\frac{Q}{q} < \frac{RD^3}{(D^2-R^2)^2} - \frac{R}{D}$$

这正是题目所给的条件，因此当 $q$ 与 $Q$ 同号且满足此不等式时，$F < 0$，**即两者之间表现为引力**。$\blacksquare$

---

> **物理直觉**：虽然 $q$ 与 $Q$ 同号（通常情况下两者排斥），但镜像电荷 $q_1 = -Rq/D$ 是异号的，且位于球内靠近 $q$ 的一侧，对 $q$ 产生吸引力。当 $Q$ 不够大时，补偿电荷 $q_2$ 提供的排斥力不足以抵消 $q_1$ 的吸引力，整体仍表现为引力。
