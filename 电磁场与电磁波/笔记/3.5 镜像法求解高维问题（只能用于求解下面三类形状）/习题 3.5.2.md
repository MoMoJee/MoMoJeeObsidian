# 习题 3.5.2 60°导体角域内点电荷的镜像

## 题目

一个点电荷 $q$ 放在 60° 接地导体角域内的点 $(1,1,0)$ 处（如图，一面沿 $x$ 轴，另一面与 $x$ 轴成 $60°$）。求：(1) 所有镜像电荷的位置和大小；(2) 点 $P(2,1,0)$ 处的电位。

---

## 基本思路

根据[[3.5.1_接地导体平面的镜像|接地导体平面的镜像法]]，对于夹角为 $\alpha = \pi/n$（$n$ 为正整数）的导体楔形角域，可以用 $2n-1$ 个镜像电荷代替两个导体面上的感应电荷效应。

本题角度为 $60° = \pi/3$，即 $n=3$，因此需要 $2\times3-1 = 5$ 个镜像电荷。

所有镜像电荷与真实电荷到角域顶点（原点）的距离相同，均为 $r = \sqrt{1^2+1^2} = \sqrt{2}$，只是分布在不同角度上。

---

## (1) 确定镜像电荷位置和大小

**坐标系设定**：两导体面分别为 $\theta=0°$（$x$ 轴）和 $\theta=60°$。实际电荷位于 $(1,1,0)$，即 $r=\sqrt{2}$、$\theta=45°$。

通过对两条导体面反复做镜像（每次镜像对导体面内的点保持原位，改变符号），可以系统地列出 5 个镜像位置：

| 镜像 | 镜像角度 | 笛卡尔坐标 | 电荷量 | 来源 |
|------|----------|-----------|--------|------|
| 1 | $-45°$（即 $315°$） | $(1,\ -1,\ 0)$ | $-q$ | $q$ 关于 $\theta=0$ 面的对称像 |
| 2 | $75°$ | $\left(\dfrac{\sqrt{3}-1}{2},\ \dfrac{\sqrt{3}+1}{2},\ 0\right)$ | $-q$ | $q$ 关于 $\theta=60°$ 面的对称像 |
| 3 | $165°$ | $\left(-\dfrac{\sqrt{3}+1}{2},\ \dfrac{\sqrt{3}-1}{2},\ 0\right)$ | $+q$ | 镜像 1（$-q$）关于 $\theta=60°$ 面的对称像 |
| 4 | $285°$ | $\left(\dfrac{\sqrt{3}-1}{2},\ -\dfrac{\sqrt{3}+1}{2},\ 0\right)$ | $+q$ | 镜像 2（$-q$）关于 $\theta=0$ 面的对称像 |
| 5 | $195°$ | $\left(-\dfrac{\sqrt{3}+1}{2},\ -\dfrac{\sqrt{3}-1}{2},\ 0\right)$ | $-q$ | 镜像 3（$+q$）关于 $\theta=0$ 面的对称像 |

> **验证**：上述 6 个电荷（1 真 + 5 像）在 $360°/60°=6$ 个等分扇区内依次交替排列，总电荷为 $q-q-q+q+q-q=0$（接地导体总感应电荷为 $-q$，与实际相符）。

**坐标推导说明**（以镜像 2 为例）：将真实电荷 $(1,1)$ 关于 $\theta=60°$ 直线（$y=\sqrt{3}x$）做镜像，反射公式为：
$$x' = x\cos(2\times60°) + y\sin(2\times60°) = -\frac{x}{2}+\frac{\sqrt{3}y}{2} = \frac{\sqrt{3}-1}{2}$$
$$y' = x\sin(2\times60°) - y\cos(2\times60°) = \frac{\sqrt{3}x}{2}+\frac{y}{2} = \frac{\sqrt{3}+1}{2}$$

---

## (2) 计算点 $P(2,1,0)$ 处的电位

电位由真实电荷和 5 个镜像电荷共同叠加（仅在原始导体角域 $0<\theta<60°$ 内适用）：

$$\varphi(P) = \frac{q}{4\pi\varepsilon_0}\left(\frac{1}{R_q} - \frac{1}{R_1} - \frac{1}{R_2} + \frac{1}{R_3} + \frac{1}{R_4} - \frac{1}{R_5}\right)$$

**各距离计算**（场点 $P(2,1,0)$）：

$$R_q = \sqrt{(2-1)^2+(1-1)^2} = 1$$

$$R_1 = \sqrt{(2-1)^2+(1+1)^2} = \sqrt{5}$$

$$R_2^2 = \left(2-\frac{\sqrt{3}-1}{2}\right)^2+\left(1-\frac{\sqrt{3}+1}{2}\right)^2 = \frac{(5-\sqrt{3})^2+(1-\sqrt{3})^2}{4} = 8-3\sqrt{3}$$

$$R_3^2 = \left(2+\frac{\sqrt{3}+1}{2}\right)^2+\left(1-\frac{\sqrt{3}-1}{2}\right)^2 = \frac{(5+\sqrt{3})^2+(3-\sqrt{3})^2}{4} = 10+\sqrt{3}$$

$$R_4^2 = \left(2-\frac{\sqrt{3}-1}{2}\right)^2+\left(1+\frac{\sqrt{3}+1}{2}\right)^2 = \frac{(5-\sqrt{3})^2+(3+\sqrt{3})^2}{4} = 10-\sqrt{3}$$

$$R_5^2 = \left(2+\frac{\sqrt{3}+1}{2}\right)^2+\left(1+\frac{\sqrt{3}-1}{2}\right)^2 = \frac{(5+\sqrt{3})^2+(1+\sqrt{3})^2}{4} = 8+3\sqrt{3}$$

因此：

$$\boxed{\varphi(P) = \frac{q}{4\pi\varepsilon_0}\left[1 - \frac{1}{\sqrt{5}} - \frac{1}{\sqrt{8-3\sqrt{3}}} + \frac{1}{\sqrt{10+\sqrt{3}}} + \frac{1}{\sqrt{10-\sqrt{3}}} - \frac{1}{\sqrt{8+3\sqrt{3}}}\right]}$$

**数值估算**（取 $\sqrt{3}\approx1.732$）：

| 项 | 值 |
|---|---|
| $1/R_q = 1$ | $1.0000$ |
| $-1/\sqrt{5}$ | $-0.4472$ |
| $-1/\sqrt{8-3\sqrt{3}} = -1/\sqrt{2.804}$ | $-0.5973$ |
| $+1/\sqrt{10+\sqrt{3}} = +1/\sqrt{11.732}$ | $+0.2920$ |
| $+1/\sqrt{10-\sqrt{3}} = +1/\sqrt{8.268}$ | $+0.3478$ |
| $-1/\sqrt{8+3\sqrt{3}} = -1/\sqrt{13.196}$ | $-0.2753$ |
| **总和** | **$\approx 0.320$** |

$$\varphi(P) \approx \frac{0.320\,q}{4\pi\varepsilon_0}$$
