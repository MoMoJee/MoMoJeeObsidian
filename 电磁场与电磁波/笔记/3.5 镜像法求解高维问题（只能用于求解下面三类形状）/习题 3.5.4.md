# 习题 3.5.4 点电荷在介质分界面上方的电位分布与极化电荷

## 题目

如图，$z<0$ 的下半空间是介电常数为 $\varepsilon$ 的电介质，上半空间为空气（$\varepsilon_0$），距介质平面 $h$ 处有一点电荷 $q$（即 $q$ 在 $(0,0,h)$ 处）。求：

1. $z>0$ 和 $z<0$ 两个半空间内的电位分布；
2. 电介质表面上的极化电荷密度，并证明表面上的极化电荷总量等于镜像电荷 $q'$。

---

## 基本思路

这是**介质分界面的镜像问题**（区别于接地导体面）。导体面的边界条件是 $\varphi=0$，而介质分界面的边界条件是：

- 切向电场连续：$E_{t,1} = E_{t,2}$（等价于 $\varphi_1|_{z=0} = \varphi_2|_{z=0}$）；
- 法向电位移矢量连续（无自由面电荷）：$D_{n,1} = D_{n,2}$，即 $\varepsilon_0 E_{z,1} = \varepsilon E_{z,2}$。

对两个半空间分别建立等效镜像模型，求镜像电荷使得两个边界条件同时满足。

---

## (1) 确定镜像电荷与电位分布

**对 $z>0$ 区域（真空）**：用真实电荷 $q$ 在 $(0,0,h)$ 加上一个位于 $(0,0,-h)$ 的镜像电荷 $q'$ 来叠加；

**对 $z<0$ 区域（介质）**：用单个位于 $(0,0,h)$ 的等效电荷 $q''$ 来表示（不再包含真实电荷 $q$，仅一个等效源），且公式中仍使用 $\varepsilon_0$。

设 $\rho = \sqrt{x^2+y^2}$，则：

$$\varphi_1 = \frac{1}{4\pi\varepsilon_0}\left[\frac{q}{\sqrt{\rho^2+(z-h)^2}} + \frac{q'}{\sqrt{\rho^2+(z+h)^2}}\right] \quad (z \geq 0)$$

$$\varphi_2 = \frac{q''}{4\pi\varepsilon_0\sqrt{\rho^2+(z-h)^2}} \quad (z \leq 0)$$

**利用边界条件确定 $q'$ 和 $q''$：**

在 $z=0$ 处，令 $R = \sqrt{\rho^2+h^2}$，此时两项分母相等：

**条件一（电位连续，$\varphi_1|_{z=0} = \varphi_2|_{z=0}$）：**

$$\frac{q + q'}{4\pi\varepsilon_0 R} = \frac{q''}{4\pi\varepsilon_0 R} \quad\Rightarrow\quad q + q' = q'' \tag{I}$$

**条件二（法向 $D$ 连续，$\varepsilon_0 E_{z,1}|_{z=0} = \varepsilon E_{z,2}|_{z=0}$）：**

对 $\varphi_1$ 求 $z$ 偏导（注意 $\partial/\partial z [1/\sqrt{\rho^2+(z\mp h)^2}]$ 在 $z=0$ 处的结果）：

$$\frac{\partial\varphi_1}{\partial z}\bigg|_{z=0} = \frac{h(q-q')}{4\pi\varepsilon_0 R^3}, \qquad \frac{\partial\varphi_2}{\partial z}\bigg|_{z=0} = \frac{hq''}{4\pi\varepsilon_0 R^3}$$

代入条件 $\varepsilon_0\times(-\partial\varphi_1/\partial z) = \varepsilon\times(-\partial\varphi_2/\partial z)$：

$$\varepsilon_0(q - q') = \varepsilon\,q'' \tag{II}$$

由 (I) 代入 (II)：$\varepsilon_0(q-q') = \varepsilon(q+q')$，解得：

$$\boxed{q' = -\frac{\varepsilon - \varepsilon_0}{\varepsilon + \varepsilon_0}\,q}$$

$$\boxed{q'' = q + q' = \frac{2\varepsilon_0}{\varepsilon + \varepsilon_0}\,q}$$

**两个半空间的电位分布：**

> **上半空间（$z \geq 0$，真空）：**
> $$\varphi_1(x,y,z) = \frac{1}{4\pi\varepsilon_0}\left[\frac{q}{\sqrt{\rho^2+(z-h)^2}} - \frac{\varepsilon-\varepsilon_0}{\varepsilon+\varepsilon_0}\cdot\frac{q}{\sqrt{\rho^2+(z+h)^2}}\right]$$

> **下半空间（$z \leq 0$，介质）：**
> $$\varphi_2(x,y,z) = \frac{1}{4\pi\varepsilon_0}\cdot\frac{2\varepsilon_0}{\varepsilon+\varepsilon_0}\cdot\frac{q}{\sqrt{\rho^2+(z-h)^2}} = \frac{q}{2\pi(\varepsilon+\varepsilon_0)\sqrt{\rho^2+(z-h)^2}}$$

**关于 $q''$ 的说明**：下半空间的电位由 $q''$ 和 $\varepsilon_0$ 写成，这并不是说介质里电场看起来像真空一样。这是镜像法的等效表达：由于介质极化，实际场的效果等同于在原电荷位置放置电荷 $q''$，在整个空间用 $\varepsilon_0$ 计算。这种写法是数学等效，能自动满足两个边界条件。

---

## (2) 极化电荷面密度及其总量

**极化电荷面密度**由介质表面上极化强度的法向分量确定：

$$\rho_{ps} = \vec{e}_n \cdot \vec{P}\big|_{\text{界面}} = \vec{e}_z \cdot (\varepsilon - \varepsilon_0)\vec{E}_2\big|_{z=0^-} = (\varepsilon-\varepsilon_0)E_{z,2}\big|_{z=0}$$

（这里 $\vec{e}_z$ 是从介质指向真空的外法线；$\vec{P} = (\varepsilon-\varepsilon_0)\vec{E}$）

计算 $E_{z,2}|_{z=0}$：

$$E_{z,2}\big|_{z=0} = -\frac{\partial\varphi_2}{\partial z}\bigg|_{z=0} = -\frac{q''}{4\pi\varepsilon_0}\cdot\frac{h}{R^3} = -\frac{2\varepsilon_0 q}{4\pi\varepsilon_0(\varepsilon+\varepsilon_0)}\cdot\frac{h}{(\rho^2+h^2)^{3/2}}$$

$$= -\frac{qh}{2\pi(\varepsilon+\varepsilon_0)(\rho^2+h^2)^{3/2}}$$

因此极化面电荷密度：

$$\boxed{\rho_{ps} = (\varepsilon-\varepsilon_0)\times\left[-\frac{qh}{2\pi(\varepsilon+\varepsilon_0)(\rho^2+h^2)^{3/2}}\right] = -\frac{(\varepsilon-\varepsilon_0)qh}{2\pi(\varepsilon+\varepsilon_0)(\rho^2+h^2)^{3/2}}}$$

**证明极化电荷总量等于 $q'$：**

对整个 $xOy$ 平面（$z=0$）积分，极坐标 $\rho \in [0,\infty)$：

$$q_p = \int_0^\infty \rho_{ps}\cdot 2\pi\rho\,d\rho = \int_0^\infty -\frac{(\varepsilon-\varepsilon_0)qh}{2\pi(\varepsilon+\varepsilon_0)(\rho^2+h^2)^{3/2}} \cdot 2\pi\rho\,d\rho$$

$$= -\frac{(\varepsilon-\varepsilon_0)qh}{\varepsilon+\varepsilon_0}\int_0^\infty\frac{\rho\,d\rho}{(\rho^2+h^2)^{3/2}}$$

利用标准积分 $\displaystyle\int_0^\infty\frac{\rho\,d\rho}{(\rho^2+h^2)^{3/2}} = \left[-\frac{1}{\sqrt{\rho^2+h^2}}\right]_0^\infty = 0 + \frac{1}{h} = \frac{1}{h}$：

$$q_p = -\frac{(\varepsilon-\varepsilon_0)qh}{\varepsilon+\varepsilon_0}\cdot\frac{1}{h} = -\frac{(\varepsilon-\varepsilon_0)q}{\varepsilon+\varepsilon_0} = \frac{(\varepsilon_0-\varepsilon)q}{\varepsilon+\varepsilon_0}$$

与镜像电荷 $q' = -\dfrac{\varepsilon-\varepsilon_0}{\varepsilon+\varepsilon_0}q = \dfrac{\varepsilon_0-\varepsilon}{\varepsilon+\varepsilon_0}q$ 完全相等，即：

$$\boxed{q_p = q'} \qquad \blacksquare$$

**物理意义**：介质被点电荷极化后，在分界面上产生的束缚（极化）电荷总量，恰好等于镜像电荷 $q'$。这表明上半空间的电场，就是 $q$ 和极化面电荷（合计为 $q'$）共同产生的——镜像方法不过是将分布的极化面电荷等效为一个集中在 $(0,0,-h)$ 的点电荷 $q'$。
