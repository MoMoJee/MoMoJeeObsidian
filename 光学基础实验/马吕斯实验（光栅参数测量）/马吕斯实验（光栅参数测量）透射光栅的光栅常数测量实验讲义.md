# 实验原理—— 衍射光栅

光栅概述：衍射光栅是一种应用非常广泛、非常重要的光学元件，通常讲的衍射光栅都是基于夫朗和费多缝衍射效应进行工作的。

由大量等宽、等间距、平行排列的狭缝 ( 或反射面 ) 构成。
